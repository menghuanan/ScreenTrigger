# 数据结构与持久化契约

## 录制草稿与脚本（TASK-034）

结束录制返回 `scope`、`actions`、`interrupted`。每个完整动作含从零递增的 `seq`、单调的 `start_ms` 和 `end_ms` 及 `action`。点击含按钮和比例点，拖动含起点、按序经过的点及终点，滚动含比例点及有符号的原始滚轮增量。键序中的每一项含 `offset_ms`、`down`，再带标准键名或 `scan_code` 与 `extended`。同毫秒的边沿按数组顺序回放。`interrupted` 用 `after` 记已完成动作数，`reason` 记中止原因。编辑器接收 Lua 源码；保存使用脚本目录已有的修订机制。

## 单像素取点回执（TASK-032）

`pointPickResult` 见 schema/types.schema.json。点使用 `screen_physical` 有符号整数，保留单像素和负屏幕原点。使用窗口绑定时，客户区点、绑定 ID 和几何修订一起返回。点只回填发起请求的脚本草稿，用户可将手工或点选的位置插入可编辑的 `click_at` 源码。

## AnchoredPoint v1（TASK-031）

字段为 `version=1`、`scope=window|region|display`、`strategy=relative|offset`、`reference_width`、`reference_height`、`x`、`y`。后四项为整数，参考宽高为 1 至 2147483647，录制局部点在参考范围半开边界内。动作中只保存定位表达。窗口客户区、显式选区和单台显示器的身份、尺寸与物理原点由本次执行租约取得。对窗口客户区内的选区使用 `region`。

数据 schema_version=2，IPC protocol_version=1，Lua API version=1 是独立版本。旧 v1 文档结构未发布实现，本轮定义不承诺兼容含糊的旧草稿。以下是规范字段表与合法 JSON 示例；不是已有程序文件。本章共享类型的机器可校验声明见 `schema/types.schema.json`（三端 validate() 单一事实源）；与本章冲突时以本章为准。

## 通用值与单位

所有 JSON 使用 UTF-8，禁止 NaN/Infinity、重复键；对象字段 snake_case；未声明字段拒绝，metadata 除外。ID 为非空不透明字符串，持久实体由 UUID 生成；示例用 t1/s1 简写，不作格式验证依据。时间戳 UTC RFC3339；协议时间/期限用整数毫秒，Lua 时长用秒；计数非负整数。

JsonValue：null、boolean、string、有限 number、JsonValue 数组、字符串键对象。跨 Lua 的整数限制在 ±(2^53−1)，超过用字符串；深度最多 32，编码后最多 1MiB。一个脚本返回零或一个值；无返回映射 null；多个返回拒绝。循环 table、混合数组/对象键、稀疏数组、函数、userdata 均拒绝。空 Lua table 默认对象；`json_array({})` 标为空数组；`json_null` 保留数组空位与对象 null 字段，nil 不能代替对象字段的 null。

## Region、Frame 与 ImageRef

| 字段 | 类型/约束 |
|---|---|
| Region.space | screen_physical / window_client_physical / image_pixel |
| Region.x,y | integer；screen 可负；client/image 不可负 |
| Region.width,height | integer ≥10；用于单像素读取的 Point 不受此限制 |
| Region.display_id | screen 空间必填；其他空间不出现 |
| Region.binding_id | client 空间必填；其他空间不出现 |
| Region.image_id | image 空间必填；其他空间不出现 |

矩形为左闭右开 `[x,x+w)×[y,y+h)`。Region 与运行 binding 不一致拒绝。RunConfig/MonitorConfig 的 region 仅允许 screen_physical / window_client_physical 空间；运行/监控范围传入 image_pixel 报 INVALID_PARAMS，定位字段 `region.space`（image_pixel 仅供截图/识别等点级与局部读取）。window_client ROI 绑定客户区且不能跨出；识别输出转 screen_physical。宿主 query_pointer 返回的 Point 同样使用 screen_physical。保存目标的条件局部 ROI 不用 Region，而使用 `LocalRect{x,y,width,height}`（相对候选 bbox，宽高≥1），防止把 10×10 框选限制错误套到局部条件。

ImageRef：`{image_id:string,width:int,height:int,format:"png"|"jpeg",sha256:string}`，引用只在当前引擎会话有效；用于存储时转为 ImageAsset。Frame：`{frame_id,image_ref,space,origin:{x,y},captured_at,geometry_revision,binding_id}`；未绑定 geometry_revision=0、binding_id=null，图像导入的 origin=(0,0)。内部图像固定 BGR uint8，供应商适配器自行转换。

会话像素注册表在登记像素（`image_id`）时**同时登记帧元数据**（`image_id → {space,origin,geometry_revision,binding_id,captured_at,frame_id}`），使 `image_id → Frame` 可**真实还原**（只读 `get_frame`），且元数据与像素**同生命周期**（释放/关闭联动清理，有界）。未登记（如选区派生帧）→ 诚实按 `image_pixel`（origin=(0,0)/geometry_revision=0/binding_id=null）兜底，**严禁伪造 `screen_physical`**。

ImageAsset：`{path:string,sha256:string,width:int,height:int,format,storage_mode:"original"|"png_lossless"}`。path 为数据根下相对路径，禁止绝对路径、..、符号链接逃逸。原导入图保持字节，识别派生图应用 EXIF 方向；截图保存完整像素 PNG。资产按 hash 命名，缩略图单列。ImageRef 不能持久化到目标文件。

## 显示器、窗口与运行辅助类型

以下对象字段均必填，除非标明可 null；HWND 等原生句柄用十进制字符串，避免前端数值精度丢失。

| 类型 | 字段与约束 |
|---|---|
| DisplayInfo | `{id:string,rect:Rect,dpi_scale:number>0,primary:boolean}`；rect为screen物理坐标，宽高正整数 |
| WindowInfo | `{window_id:string,handle:string,pid:integer,process_started_at:string,title:string,process_name:string,client_rect:Rect,visible:boolean,minimized:boolean,foreground:boolean,geometry_revision:integer}`；window_id为当前枚举会话不透明ID |
| WindowBinding | `{binding_id:string,window_id:string,handle:string,pid:integer,process_started_at:string}`；必须同时匹配身份元组 |
| WindowSnapshot | `{binding:WindowBinding,client_rect:Rect,geometry_revision:integer,visible:boolean,minimized:boolean,foreground:boolean}`；不存在时抛WINDOW_NOT_FOUND，不返回空rect |
| SelectionSession | `{selection_id:string,display_id:string,status:"selecting",started_at:string}`；结束后不复用ID |
| Page | `{items:array,total:integer}`；offset/limit属于请求，不改变持久数据 |
| CommitResult | `{generation:string}`；current已切换且校验成功 |

Rect为 `{x:integer,y:integer,width:integer,height:integer}`，不是自动携带空间的Region。窗口最小化时可保留最近几何快照但标minimized=true，调用方不得用于捕获或输入。

hello 返回的 `model_manifests` 元素为 ModelManifest，字段英文命名如下：`{provider_id:string非空, api_version:integer≥1, provider_version:string非空, supported_condition_types:["template"|"contour"|"ocr"|"color"]数组, model_ids:[string非空], supported_languages:[string], thread_safe:boolean, offline:boolean, license:string, source:string, sha256:64位十六进制, supported_charsets:[string]}`。ProviderManifest 为 ModelManifest 去除 license/source/sha256/supported_charsets 四字段。`capabilities` 元素为 `{id,state:"available"|"pending"|"unavailable",reason:string或null}`（语义见 03）。机器声明以 `schema/types.schema.json` 为准，冲突时以本章为准。
## Target 与条件树

```json
{
  "schema_version": 2,
  "next_sample_no": 2,
  "targets": [{
    "id": "t1",
    "sample_no": 1,
    "revision": 1,
    "name": "开始按钮",
    "group_id": null,
    "image": {"path": "images/example.png", "sha256": "aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa", "width": 120, "height": 40, "format": "png", "storage_mode": "original"},
    "thumbnail_path": null,
    "anchor_condition_id": "c1",
    "conditions": {
      "op": "all",
      "children": [
        {"id": "c1", "type": "template", "params": {"threshold": 0.85, "allow_scale": false}},
        {"id": "c2", "type": "ocr", "params": {"text": "开始", "match_mode": "exact", "min_confidence": 0.7, "model_id": "installed-zh-model", "case_sensitive": true}}
      ]
    },
    "created_at": "2026-09-21T09:00:00Z",
    "updated_at": "2026-09-21T09:00:00Z",
    "metadata": {}
  }]
}
```

字段均必填，thumbnail_path/group_id 可 null。revision 从 1 递增；sample_no ≥1，全库唯一、不重用；next_sample_no 必须大于已有最大值，删除不回退。name 去除首尾空白后 1–100 Unicode 字符，字符计数单位为 Unicode 码点（非 UTF-16 码元、非字形簇）；不是文件名，不禁止常规标点。metadata 是最多 16KiB 的 JSON 对象，不参与识别。

条件节点为 `{op:"all"|"any",children:[Node,...]}` 或叶 `{id,type,params,roi?:LocalRect}`；叶 ID 在目标内唯一；1–10 叶，嵌套最多 4 层。anchor_condition_id 必须指向存在的叶；anchor 在整帧上产候选且必须成功；其余树在该候选内评估，故整体语义是 `anchor 命中 AND 条件树为真`。希望 OR 在多个不同定位算法间切换，应创建不同目标；不能偷偷绕开 anchor。

| 叶类型 | params 必填 | 默认/选填 | 计算规则 |
|---|---|---|---|
| template | threshold:0..1 | allow_scale=false；启用时 scale_range=[0.95,1.05]，step=0.01 | TM_CCOEFF_NORMED；分数 clamp 到 0..1；模板来自 Target.image |
| feature_match | 无 | min_inliers=8（4..1500），min_inlier_ratio=0.45（0..1），max_reprojection_error=3.0（0.1..20 源帧像素） | ORB v1，Hamming 匹配和 RANSAC 相似变换。从 Target.image 定位，只交付范围内最佳单框。 |
| contour | threshold:0..1 | min_area=16；canny_low=50,canny_high=150 | 灰度→Canny→外轮廓→matchShapes I1；score=1/(1+distance)，与 0.85 比较 |
| ocr | text 非空，model_id | match_mode=exact/contains/fuzzy（默认 exact），min_confidence=.7，case_sensitive=true，fuzzy_threshold=.8 | NFC 归一化后比較；原始文本保留；fuzzy=1−Levenshtein/max(len)，0..1 |
| color | color_space、color | tolerance RGB={r:15,g:15,b:15} / HSV={h:10,s:20,v:20}，min_pixel_count=1，min_percentage=0 | 8 连通分量产候选；所有非零阈值须同时满足 |

template/contour 默认阈值均为 0.85，但分数不是准确率，也不可跨算法理解成同一种概率。轮廓最小面积可配置整数≥1；canny_low/high 为 0–255 且 low<high。模板为空、纯色或大于源帧且无合法缩放候选时报 INVALID_IMAGE。模板候选做 NMS（IoU>0.5 合并，保留分数较高者）；轮廓候选按相同规则去重。最多返回 100 个候选，标 `truncated=true`。

颜色 RGB 值/容差均为整数 0–255，每通道同时满足绝对差≤容差。HSV 的 h∈[0,360)，s/v∈[0,100]；h 按整数实现，实现域为 [0,359] 闭区间（h=360 拒绝，报 INVALID_PARAMS 定位 `conditions.params.color.h`）；h 容差 0–180，s/v 容差 0–100，h 按圆周最短距离。OpenCV H=0–179 的转换只在适配器内部。min_percentage 为该连通分量像素数占当前检测 ROI 的百分比，0–100。色彩空间已冻结为 HSV（用户 2026-10-09 确认）；`hsc` 不是合法 color_space，生成即 INVALID_PARAMS。

### 目标检测扩展契约 v1

独立的 `object_detect` 契约以模型清单的 `model_id/version` 和声明的非负整数类别 ID 识别检测器。请求携带模型 ID、类别、阈值和源帧局部半开 ROI，执行上下文提供现有 Frame 与取消令牌。模型输入固定为 RGB、NCHW、float32 的 [0,1] 数值。将 BGR 字节换序并除以 255，ROI 保持宽高比缩入模型输入，缩放后的宽高最近取整、恰半向上，至少 1 像素；左右和上下各居中，奇数补边把多余一像素放右或下，填充 RGB(114,114,114)。适配器按各轴实际缩放宽高还原坐标。

解码张量为 N×6，列序是 x1、y1、x2、y2、confidence、class_id。框按输入网格的连续边界计。去除补边部分，再向外取整，平移 ROI 与 Frame.origin 各一次，得到 Frame.space 的半开整数框。纯补边框丢弃。每个结果含类别、bbox、center、confidence 和 space，外层保留 frame_id、geometry_revision、matches 与 truncated。分数相同时保留原行顺序；清单声明需要外部 NMS 时，在请求类别内按 IoU > 0.5 抑制低分实例，结果最多 100 个。空数组是合法未命中。[机器契约](../schema/object-detection-v1.schema.json)

## Group 与 Script

Group：`{id,revision,name,parent_group_id,depth,created_at,updated_at}`；层级分组最多 3 层（depth 0..2，用户 2026-10-09 确认），parent_group_id 顶层为 null、否则指向存在组且 depth=父+1；名称 1–100 字符（同目标名称按 Unicode 码点计数），NFC+大小写折叠后**同层**组名唯一；目标通过 group_id=null 表示未分组；删除组时其直接目标成员移至未分组（group_id=null）、子分组提升到被删组的父位置（depth 减 1），单次事务；target_count 查询时派生，不持久化第二份计数。

Script：`{id,revision,name,source_path,source_sha256,parameters,created_at,updated_at}`；source_path=`scripts/<id>/<hash>.lua`，UTF-8、≤1MiB。parameters 数组元素 `{name,type,required,default,description}`，type 为 string/number/boolean/object/array，required 为 true 时 default 必须 null（不自动使用）；可选参数按 default 补齐。只声明一级类型，嵌套使用 JsonValue；未声明参数拒绝。监控动作脚本应声明 `match:object`，超时脚本声明 `failure:object`；一般子脚本由用户显式声明输入字段。

## RunConfig 与 MonitorConfig（仅内存）

本轮的启动命令可另带会话级 `output_token`，由宿主的 TXT 选择器签发，绑定 append 或 overwrite。用户没有启用导出时省略它。令牌不写入脚本、运行配置、历史或备份。每次 OCR 调用及每个启用导出的监控采样各有独立的逻辑动作 ID。

RunConfig：

| 字段 | 类型、默认与验证 |
|---|---|
| script_id | string，已保存脚本必填 |
| args | JsonValue object，默认 {}，按 Script.parameters 验证 |
| mode | once/count/forever/until_target，默认 once |
| iterations | count 必填 integer≥1；其他模式 null |
| stop_target_id | until_target 必填；其他 null |
| debug | boolean=false；与循环模式正交 |
| region | Region 或 null（null 表示选定显示器全屏或绑定客户区） |
| display_id | 未绑定必填；绑定时 null |
| binding_id | string 或 null |
| allow_exit | boolean=false；只影响输入，不扩大识别区域 |
| frequency_hz | number 0.1–30，默认 1 |
| total_timeout_ms | integer≥0，默认 0 无期限；不含暂停时间 |

MonitorConfig 复用 RunConfig 的 region/display_id/binding_id/allow_exit/frequency_hz/total_timeout_ms/debug；不包含 script_id/args/mode/iterations/stop_target_id，另外必填 target_id。

| 监控字段 | 默认与条件 |
|---|---|
| repeat | false：首次命中动作完成后结束；true：成功动作完成后持续监控；on_match=stop时必须false |
| wait_timeout_ms | 30000；0 无期限 |
| on_match | run_script 或 stop；默认 stop |
| action_script_id / action_args | run_script 必填 ID，否则 null；args 默认 {}，match 由宿主覆盖注入 |
| on_timeout | stop/retry/run_script，默认 stop |
| timeout_script_id / timeout_args | run_script 必填 ID，否则 null；args 默认 {}，failure 由宿主注入 |
| max_retries | integer 0–100，默认 0；on_timeout=retry 时须≥1，其他必须 0 |
| retry_delay_ms | integer≥0，默认 1000 |
| trigger | rising_edge/every_match，默认 rising_edge |
| cooldown_ms | integer≥0，默认 1000 |

配置一旦启动生成不可变快照；临时区/窗口身份不写到 config、脚本元数据或可复用工作区。历史日志可以保存当次区域快照作诊断，UI 不提供复用该快照按钮。

## RecognitionResult、Match 和状态

```json
{
  "target_id": "t1",
  "sample_no": 1,
  "target_revision": 1,
  "frame_id": "frame-1",
  "found": true,
  "matches": [{
    "target_id": "t1", "sample_no": 1,
    "space": "screen_physical",
    "bbox": {"x": -900, "y": 200, "width": 120, "height": 40},
    "center": {"x": -840, "y": 220},
    "confidence": 0.92,
    "geometry_revision": 1,
    "evidence": [{"condition_id": "c1", "matched": true, "confidence": 0.92}, {"condition_id": "c2", "matched": true, "text": "开始", "confidence": 0.95}]
  }],
  "elapsed_ms": 80,
  "truncated": false
}
```

Match.confidence 取 anchor 的分数；颜色 anchor 分数为匹配像素/候选框面积（0..1），不是全帧比例。center 为 bbox 中心取 floor。evidence 对每个叶含 matched、confidence（无概率时 null）、可选 text；短路未执行的叶记 skipped=true、matched=null，不能伪造分数。found 必须等价于 matches 非空；未命中不得附带上次坐标。

TextBlock：`{text,confidence,polygon:[{x,y},...],space,model_id,language}`；polygon 四点同序、物理/图片像素；language 在引擎无法判断时 null，不编造检测语言。

OCR 语言与匹配（TASK-015）：`model_id` 决定语言（命令无 `language` 形参）；`TextBlock.language` 取自**模型 manifest 实证值**，多语通用模型无单一语言 → `null`（不编造）。文本匹配 `exact`/`contains`/`fuzzy` 在 **NFC 归一后**比较、原始文本保留；`fuzzy` 相似度（`1−Levenshtein/max(len)`，0..1）**只**决定 `matched`，**不写入** `evidence.confidence`（后者为 OCR 识别分，口径同 TASK-014「分数不是概率」）。`TextBlock.polygon` 为**源图 0 基像素**，`space==frame.space`；从裁剪局部平移回 `frame.space` 由消费层完成且只做一次（`textmatch.translate_polygon_to_space`，`space=="screen_physical"` 只能来自已登记帧元数据，严禁伪造）。模型元数据（逐文件 sha256 + 许可证 + 语言）为**新增只读** `manifest/models.catalog.json`（不入三端共享 schema）与 02 磁盘布局 `models/<model_id>/manifest.json`（`ModelManifest`，仅元数据、不含权重）。

ExecutionState：`{execution_id,kind:"script"|"monitor",status,reason,iteration,script_id,current_line,result,error,started_at,updated_at,effective_hz,throttled}`；status 为 starting/running/paused/debug_paused/stopping/completed/cancelled/failed；reason/result/error 可 null，script_id 在纯 monitor 时 null。终态不再转回 running；result 只保留最后一次脚本结果，监控返回 `{match_count,last_match}`，没有结果为 null；逐轮结果写历史。

theme=system/light/dark；language 首版 UI 支持 zh-CN（OCR 语言另算）；threshold/ocr_min_confidence 0..1；png_compression_level 0..9；preview_hz 1..20；move_duration_ms 0..5000；type_interval_ms 0..5000。本节的机器可校验声明（逐字段默认值与 configLimits 范围常量）见 `schema/config.schema.json`，与本章冲突时以本章为准。frequency_hz/容差同前表；total_timeout_ms≥0。logging.level=debug/info/warning/error；rotate_bytes 1MiB..100MiB；file_count 1..20。model_directory 为数据根相对目录且不可越界；不可任意下载网络模型。ocr_model_id=null 时文字识别禁用，纯脚本/其他识别仍可用。

不提供 max_script_concurrency、sandbox 开关、saved_regions 或联网 API key 字段。常量限额见 06，不是用户可以关闭的运行规则。配置优先级：运行显式参数 → 已保存配置 → 本表默认值；target 条件显式值优先于创建时默认阈值。更新已有目标不因全局阈值变更而改变。

## 磁盘布局与一致提交

全新安装的数据根建议 `%LOCALAPPDATA%/ScreenTrigger/`，由 Rust 宿主解析后传给引擎。升级要检查旧宿主实际采用的目录（包括旧应用标识的本地目录及既有回退目录）。唯一有效数据根继续使用，多份有效时由用户选择并先备份，禁止因换壳而新建空库遮蔽原数据。开发与测试使用显式隔离目录。所有资产和源码归应用保存，脚本本身仍不能访问文件。

```text
config.json
catalog/current.json                 # {generation: "g...", manifest_sha256: "..."}
catalog/generations/<generation>/
  manifest.json                      # schema、文件 hashes、计数
  targets.json
  groups.json
  script_metadata.json
images/<sha256>.<ext>                 # 不可变资产
scripts/<id>/<source_sha256>.lua      # 不可变源码
models/<model_id>/manifest.json
history/<execution_id>.jsonl          # UTF-8 RunLog；旧分卷后缀 .1 至 .N
history/<execution_id>.json           # 脱敏摘要，重启后可查看
backups/
```

目录备份保存在 `backups/b-<32位十六进制>/`。每份包含原 current、它引用的完整 generation、该快照引用的原图和 Lua 源码。目录可整体复制至另一数据根的 backups。预览校验目录文件、数量、实体、外键、内容寻址和资源预算，返回目标数量、脚本数量、下一样本号及当前指针指纹。恢复使用新的 generation，旧编号和条件原样保留，下一样本号至少为原库已分配的上界。配置继续由 ConfigService 单独管理。

一个 Repository 写锁串行提交：写新资产/源码 → 写新 generation 的三个 JSON 和 manifest → flush/fsync → 校验所有外键/哈希 → 同卷临时写 current 指针 → 原子替换 current → 更新内存快照 → 返回成功。切换前失败不影响旧 generation；切换后崩溃读取完整新 generation。Windows 文件占用重试有限且不覆盖原数据；旧 generation/资产保留到无活动引用且备份成功再回收。单文件 config 使用同卷临时文件+fsync+原子替换+备份。

current 损坏：只读检查可用备份，提示恢复，不自动建空库覆盖。schema 高于支持版本：拒绝写入并提示升级；不静默删除未知字段。历史 v1 扁平 operator 条件有歧义，导入前必须显示转换预览并要求用户选择；不能猜测运算优先级。

## SQLite 后续映射和迁移

建议表：`targets(id PK,sample_no UNIQUE,revision,name,group_id FK,image_json,conditions_json,anchor_condition_id,metadata_json,created_at,updated_at)`；`groups(id PK,revision,name,parent_group_id FK NULL,depth INTEGER 0..2,created_at,updated_at)`；`scripts(id PK,revision,name,source_path,source_sha256,parameters_json,created_at,updated_at)`；`meta(key PK,value)` 保存 schema_version/next_sample_no。启用 foreign_keys；删除组时目标 group_id SET NULL、子组 parent 提升并重算 depth；条件 JSON 与图片外部资产保留原契约。

迁移在无活动执行且持有写锁时：备份整个有效 generation/资产 → 临时数据库事务导入 → 验证 ID、计数、最大编号、外键、哈希和逐实体归一化内容一致 → 关闭连接 → 原子切换后端选择指针。失败丢弃临时库、保持 JSON；切换后若尚无写入可切回备份，有新写入必须逆向导出后再切回，不能丢弃新增数据。首版不实现自动迁移或运行时双写。

原生应用使用 `desktop/ScreenTrigger/Contracts/` 中的 C# 类型读取配置、区域、帧、目标、匹配、运行参数、错误与能力。类型和配置的 JSON Schema 随应用内嵌。缺省字段与显式 null 按声明分别校验，配置的深补丁由后端持写锁提交。显示坐标及模型验证按[现行验收矩阵](agent/验收与测试.md)复测，历史证据按[检查与闭环](agent/检查与闭环.md)核验。

执行历史摘要含 execution_id、kind、script_id、status、reason、started_at、updated_at、iteration、effective_hz、throttled、sample_no 和 error_code。启动配置、源码、脚本结果、识别文本及输入参数不写入摘要。按 updated_at 倒序分页。

## 后续自动化版本的 OCR 模型库

模型库快照含整数 revision 和 pipelines 数组。每条管线以已有识别端 model_id 标识，列出 languages、检测和识别组件、离线文件总字节、state 及最近的错误。状态为 missing（未装）、installed（已装待首次加载）、loading、ready 或 damaged。数据根模型目录的 library/current.json 保存 schema_version=1、revision 和每条管线的来源。初始随包来源和导入的不可变对象分别解析；移除持久保存。静态可信目录决定组件、文件长度、哈希和许可。
## 脚本动作策略

自动化扩展的 Script 可带 `action_policy`。版本 1 对象含 `version: 1`，以及可选的 `curve`、`offset`、`delay_ms`。每项写 `false` 表示关闭。启用曲线时传 `{"c1":[dx,dy],"c2":[dx,dy]}`，前一个控制点相对于起点，后一个相对于终点，单位为物理像素。偏移传 `{"x":[min,max],"y":[min,max]}`，延迟传整毫秒闭区间 `[min,max]`。坐标分量限 ±32768，等待限 0 至 5000 毫秒。省略整个策略时三项关闭。运行读取本次脚本修订快照，调用子脚本时使用子脚本自己的配置。

## 绑定窗口取像模式

`RunConfig` 与 `MonitorConfig` 可带 `window_mode`。缺省值为 `foreground`。显式 `background` 要求非空 `binding_id` 和空 `display_id`。执行受理时固定模式，租约使用相同模式。客户区 ROI 沿用 `window_client_physical`，结果帧保留当前绑定、屏幕物理原点和几何修订。
## 录制草稿

宿主在显式录制会话内保管动作草稿。动作含单调的 `start_ms`、`end_ms`、同时间的 `seq`，以及 `click`、`drag`、`scroll` 或 `key_sequence`。鼠标点使用版本 1 相对锚点。键组合保存已配对的按下与抬起次序。无法转换、越界和未配对操作记在 `interrupted`，其中 `after` 指最后一个完整动作之后的位置。当前仅通过 `finish_recording` 在内存中返回完整动作；本代磁盘脚本的生成及保存由 TASK-034 接入。
后台输入能力快照以 `binding_id` 标识当前窗口，五个动作分别披露能力和失败原因。后台租约维护独立的窗口内虚拟指针，初始定位于所选客户区或 ROI 的中心。键鼠持有状态和清理消息仅指向该执行实际使用的接收控件。

## 用户端脚本热键

Script 可带 `hotkey`，值为 A–Z 或 F1–F12。省略表示未绑定。一个脚本库中每个键最多绑定一个脚本。绑定随脚本元数据、备份和便携数据一起保存。
