## 1. 应用启动流程

```
用户启动应用
    ↓
┌─────────────────────────┐
│  Tauri 前端进程启动     │
│  - 初始化窗口           │
│  - 加载UI组件           │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  启动 Python 后端进程   │
│  - 初始化各个模块       │
│  - 加载配置文件         │
│  - 初始化OCR引擎        │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  加载本地数据           │
│  - targets.json         │
│  - groups.json          │
│  - config.json          │
│  - scripts metadata     │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  建立 IPC 通信          │
│  - 注册命令处理器       │
│  - 设置事件监听         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  注册全局快捷键         │
│  - Ctrl+Alt+S (框选)    │
│  - Ctrl+Alt+X (停止)    │
│  - Ctrl+Alt+P (暂停)    │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  发送 system_ready 事件 │
└────────┬────────────────┘
         ↓
      应用就绪
```

## 2. 屏幕框选流程

```
用户触发框选（点击按钮或快捷键 Ctrl+Alt+S）
    ↓
┌─────────────────────────┐
│  前端调用命令           │
│  start_selection_mode   │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  Python 后端处理        │
│  - 获取当前显示器信息   │
│  - 截取全屏图像         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  发送 selection_started │
│  事件                   │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  前端显示框选UI         │
│  - 主窗口瞬间隐藏       │
│  - 创建全屏透明窗口     │
│  - 显示截图作为背景     │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  用户拖拽鼠标框选       │
│  ┌────────────────────┐ │
│  │  实时更新选框      │ │
│  │  - 显示坐标和尺寸  │ │
│  │  - 生成预览缩略图  │ │
│  └────────────────────┘ │
└────────┬────────────────┘
         ↓
    用户松开鼠标
         ↓
┌─────────────────────────┐
│  验证框选区域           │
│  - 检查最小尺寸(10x10)  │
│  - 计算DPI适配坐标      │
└────────┬────────────────┘
         │
         ├─→ 无效 ─→ 显示错误提示
         │
         ↓ 有效
┌─────────────────────────┐
│  截取选定区域           │
│  - 使用DPI适配后的坐标  │
│  - 生成Base64图像数据   │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  发送 selection_        │
│  completed 事件         │
│  - 包含区域信息         │
│  - 包含图像数据         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  前端处理结果           │
│  - 关闭框选窗口         │
│  - 主窗口自动恢复       │
│  - 显示预览图像         │
└────────┬────────────────┘
         ↓
      框选完成
```

## 3. 目标创建流程

```
用户完成框选（或上传图片）
    ↓
┌─────────────────────────┐
│  前端显示创建对话框     │
│  - 输入目标名称         │
│  - 选择分组             │
│  - 配置识别条件         │
│  - 选择保存选项         │
└────────┬────────────────┘
         ↓
    用户点击确认
         ↓
┌─────────────────────────┐
│  前端调用命令           │
│  create_target          │
│  - 目标信息             │
│  - Base64图像数据       │
│  - 识别条件             │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  Python 后端验证        │
│  - 检查名称是否为空     │
│  - 验证图像数据         │
│  - 验证条件参数         │
└────────┬────────────────┘
         │
         ├─→ 验证失败 ─→ 返回错误
         │
         ↓ 验证成功
┌─────────────────────────┐
│  生成目标ID (UUID)      │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  保存图片文件           │
│  - 解码Base64           │
│  - 保存原图             │
│  - 生成缩略图(200x200)  │
│  - 可选：压缩图         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  创建目标对象           │
│  - 设置元数据           │
│  - 关联分组             │
│  - 保存识别条件         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  更新 targets.json      │
│  - 追加新目标           │
│  - 原子性写入           │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  返回成功响应           │
│  - 目标ID               │
│  - 创建时间             │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  前端更新UI             │
│  - 刷新目标列表         │
│  - 显示成功提示         │
│  - 跳转到目标详情       │
└─────────────────────────┘
```

## 4. 脚本执行流程

### 4.1 正常执行模式
```
用户点击"运行脚本"
    ↓
┌─────────────────────────┐
│  前端调用命令           │
│  execute_script         │
│  - script_id            │
│  - mode (执行模式)      │
│  - args (参数)          │
│  - 窗口绑定(可选)       │
│  - 区域限制(可选)       │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  Python 加载脚本文件    │
│  - 读取 .lua 文件       │
│  - 解析脚本元数据       │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  验证脚本语法           │
│  - Lua 语法检查         │
└────────┬────────────────┘
         │
         ├─→ 语法错误 ─→ 返回错误
         │
         ↓ 语法正确
┌─────────────────────────┐
│  初始化 Lua VM          │
│  - 创建隔离环境         │
│  - 注入全局变量         │
│    * args               │
│    * SCRIPT_ID          │
│    * EXECUTION_ID       │
│  - 注册API函数          │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  应用执行设置           │
│  - 绑定窗口(如果指定)   │
│  - 设置区域限制         │
│  - 设置识别频率         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  发送 script_started    │
│  事件                   │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  执行脚本 main()        │
└────────┬────────────────┘
         │
         ├──────────────────────────┐
         │                          │
         ↓ loop_once                ↓ loop_n_times
┌─────────────────────┐    ┌─────────────────────┐
│  执行一次后停止     │    │  循环执行N次        │
└─────────────────────┘    │  - iteration=1..N   │
                           │  - 每次发送         │
         ↓                 │    script_iteration │
                           │    事件             │
         ↓                 └──────┬──────────────┘
    loop_until_stop                │
┌─────────────────────┐            │
│  永久循环           │            │
│  - 直到手动停止     │◄───────────┘
│  - 或 stop_script() │
└─────────┬───────────┘
          │
          ↓ loop_until_target
┌─────────────────────┐
│  检测到目标后停止   │
│  - 每次迭代检查     │
│  - 目标出现时退出   │
└─────────┬───────────┘
          │
          ↓
    脚本执行完成
          ↓
┌─────────────────────────┐
│  清理资源               │
│  - 释放Lua VM           │
│  - 解除窗口绑定         │
│  - 清除区域限制         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  发送 script_completed  │
│  或 script_error 事件   │
│  - 执行结果             │
│  - 错误信息(如果有)     │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  前端显示结果           │
│  - 执行时间             │
│  - 返回值               │
│  - 错误提示(如果失败)   │
└─────────────────────────┘
```

### 4.2 中途停止流程
```
用户点击"停止"或按 Ctrl+Alt+X
    ↓
┌─────────────────────────┐
│  前端调用命令           │
│  stop_script            │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  Python 设置停止标志    │
│  - should_stop = true   │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  脚本检测到停止标志     │
│  (在 wait/wait_for_     │
│   target 等函数中)      │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  脚本主动退出           │
│  或被强制中断           │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  发送 script_stopped    │
│  事件                   │
│  - reason: "manual"     │
└─────────────────────────┘
```

## 5. 目标识别流程

### 5.1 单目标识别
```
脚本调用 wait_for_target(target_id, timeout)
    ↓
┌─────────────────────────┐
│  加载目标信息           │
│  - 读取目标元数据       │
│  - 加载图像文件         │
│  - 解析识别条件         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  开始循环检测           │
│  (按配置的频率)         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  截取屏幕               │
│  - 全屏或限定区域       │
│  - 或绑定窗口的客户区   │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  遍历目标的识别条件     │
└────────┬────────────────┘
         │
         ├─→ 条件1: template
         │   ┌──────────────────┐
         │   │  模板匹配        │
         │   │  - TM_CCOEFF_    │
         │   │    NORMED        │
         │   │  - 阈值过滤      │
         │   └─────┬────────────┘
         │         ↓
         │   匹配结果
         │
         ├─→ 条件2: ocr
         │   ┌──────────────────┐
         │   │  OCR识别         │
         │   │  - PaddleOCR     │
         │   │  - 文本匹配      │
         │   │  - 置信度过滤    │
         │   └─────┬────────────┘
         │         ↓
         │   识别结果
         │
         ├─→ 条件3: color
         │   ┌──────────────────┐
         │   │  颜色检测        │
         │   │  - RGB/HSV比较   │
         │   │  - 容差范围判断  │
         │   └─────┬────────────┘
         │         ↓
         │   检测结果
         │
         ↓
┌─────────────────────────┐
│  按照运算符组合结果     │
│  - AND: 所有条件都满足  │
│  - OR: 任一条件满足     │
└────────┬────────────────┘
         │
         ├─→ 条件不满足 ─→ 继续等待
         │                  ↓
         │           ┌──────────────┐
         │           │  检查超时    │
         │           └──┬───────┬───┘
         │              │       │
         │    未超时 ←──┘       └─→ 超时
         │      ↓                   ↓
         │  继续循环        返回 found=false
         │
         ↓ 条件满足
┌─────────────────────────┐
│  发送 target_detected   │
│  事件                   │
│  - 目标ID               │
│  - 位置信息             │
│  - 置信度               │
└────────┬────────────────┘
         ↓
    返回 found=true, position
```

### 5.2 多条件组合示例
```
条件1: template (threshold=0.85)
条件2: ocr (text="登录")
运算符: AND

执行流程：
1. 模板匹配 → confidence=0.92 → 通过
2. AND 运算，继续下一条件
3. OCR识别 → 找到"登录"文本 → 通过
4. 最终结果：目标匹配成功

---

条件1: color (红色)
条件2: color (蓝色)
运算符: OR

执行流程：
1. 红色检测 → 未找到
2. OR 运算，继续下一条件
3. 蓝色检测 → 找到 → 通过
4. 最终结果：目标匹配成功
```

## 6. 调试执行流程

```
用户在脚本编辑器中设置断点
    ↓
┌─────────────────────────┐
│  前端调用命令           │
│  add_breakpoint         │
│  - script_path          │
│  - line                 │
│  - condition (可选)     │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  Python 保存断点        │
│  - 生成断点ID           │
│  - 添加到断点管理器     │
└─────────────────────────┘

    用户点击"调试运行"
         ↓
┌─────────────────────────┐
│  execute_script         │
│  mode = "step"          │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  初始化调试器           │
│  - 启用Lua调试钩子      │
│  - 加载断点列表         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  脚本开始执行           │
└────────┬────────────────┘
         │
    每执行一行代码
         ↓
┌─────────────────────────┐
│  调试钩子触发           │
│  - 获取当前行号         │
│  - 获取局部变量         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  检查是否命中断点       │
└────────┬────────────────┘
         │
         ├─→ 未命中 ─→ 继续执行
         │
         ↓ 命中断点
┌─────────────────────────┐
│  暂停脚本执行           │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  发送 breakpoint_hit    │
│  事件                   │
│  - 断点ID               │
│  - 当前行号             │
│  - 变量快照             │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  前端显示调试界面       │
│  - 高亮当前行           │
│  - 显示变量面板         │
│  - 显示调用栈           │
│  - 启用调试按钮         │
└────────┬────────────────┘
         ↓
    用户选择操作
         │
         ├─→ 单步跳过 (Step Over)
         │   ┌────────────────┐
         │   │  执行下一行    │
         │   └────────────────┘
         │
         ├─→ 单步进入 (Step Into)
         │   ┌────────────────┐
         │   │  进入函数内部  │
         │   └────────────────┘
         │
         ├─→ 单步跳出 (Step Out)
         │   ┌────────────────┐
         │   │  退出当前函数  │
         │   └────────────────┘
         │
         ├─→ 继续执行 (Continue)
         │   ┌────────────────┐
         │   │  运行到下一断点│
         │   └────────────────┘
         │
         └─→ 停止调试
             ┌────────────────┐
             │  结束脚本执行  │
             └────────────────┘
```

## 7. 窗口绑定流程

```
用户点击"绑定窗口"
    ↓
┌─────────────────────────┐
│  前端调用命令           │
│  list_windows           │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  Python 枚举窗口        │
│  - 调用 Win32 API       │
│  - EnumWindows          │
│  - 过滤可见窗口         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  返回窗口列表           │
│  - 窗口句柄             │
│  - 窗口标题             │
│  - 进程名称             │
│  - 窗口位置             │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  前端显示窗口选择器     │
│  - 列表展示所有窗口     │
│  - 显示窗口图标和标题   │
└────────┬────────────────┘
         ↓
    用户选择目标窗口
         ↓
┌─────────────────────────┐
│  前端调用命令           │
│  bind_window            │
│  - window_handle        │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  Python 验证窗口        │
│  - 检查窗口是否存在     │
│  - 检查窗口是否可见     │
└────────┬────────────────┘
         │
         ├─→ 验证失败 ─→ 返回错误
         │
         ↓ 验证成功
┌─────────────────────────┐
│  保存窗口绑定           │
│  - 存储窗口句柄         │
│  - 监听窗口状态         │
└────────┬────────────────┘
         ↓
┌─────────────────────────┐
│  后续操作自动应用       │
│  - 截图限制在窗口内     │
│  - 坐标转换为窗口相对   │
│  - 输入操作发送到窗口   │
└─────────────────────────┘

    绑定后执行脚本
         ↓
┌─────────────────────────┐
│  每次截图前检查         │
│  - 窗口是否存在         │
│  - 窗口是否最小化       │
└────────┬────────────────┘
         │
         ├─→ 窗口不可用 ─→ 暂停/报错
         │
         ↓ 窗口可用
┌─────────────────────────┐
│  截取窗口客户区         │
│  - 获取窗口位置         │
│  - 转换绝对坐标         │
│  - 执行截图操作         │
└─────────────────────────┘
```
