# 模块拆分设计

## 模块总览
系统分为8个核心模块，每个模块职责单一，通过明确的接口通信。

```
1. Screen Capture Module      (屏幕捕获)
2. Vision Engine Module        (视觉识别引擎)
3. Target Manager Module       (目标管理)
4. Script Engine Module        (脚本引擎)
5. Input Simulator Module      (输入模拟)
6. Window Manager Module       (窗口管理)
7. Debug Service Module        (调试服务)
8. IPC Bridge Module           (前后端桥接)
```

---

## 1. Screen Capture Module (屏幕捕获模块)

### 职责
- 截取屏幕指定区域的图像
- 管理多显示器环境
- 提供实时框选预览

### 关键组件
```
ScreenCapture/
├── capture_core.py          # 核心截图逻辑
├── display_manager.py       # 多显示器管理
├── selection_overlay.py     # 框选UI（通过Tauri调用）
└── coordinate_mapper.py     # 坐标转换（DPI适配）
```

### 核心功能
#### 1.1 全屏截图
```python
def capture_full_screen(display_index: int = 0) -> np.ndarray
```
- **输入**: 显示器索引（0=主显示器）
- **输出**: BGR格式的numpy数组
- **约束**: 自动适配DPI缩放

#### 1.2 区域截图
```python
def capture_region(x: int, y: int, width: int, height: int, 
                   display_index: int = 0) -> np.ndarray
```
- **输入**: 左上角坐标(x,y) + 宽高 + 显示器索引
- **输出**: 截图数组
- **约束**: 
  - 最小尺寸 10x10 像素
  - 超出屏幕范围时自动裁剪
  - 坐标为屏幕绝对坐标

#### 1.3 窗口截图
```python
def capture_window(window_handle: int) -> np.ndarray
```
- **输入**: Windows窗口句柄（HWND）
- **输出**: 窗口客户区截图
- **约束**: 窗口最小化时返回空图像

#### 1.4 实时框选数据流
```python
def start_selection_stream() -> Iterator[SelectionData]
# SelectionData: {x, y, width, height, preview_thumbnail}
```
- **输出**: 持续输出框选数据（每50ms）
- **预览缩略图**: 200x200 压缩预览
- **显示信息**: 实时坐标和尺寸（叠加在Tauri UI上）

### 数据结构
```python
@dataclass
class ScreenInfo:
    index: int              # 显示器索引
    x: int                  # 虚拟屏幕中的偏移
    y: int
    width: int
    height: int
    dpi_scale: float        # DPI缩放比例
    is_primary: bool
```

### 错误处理
- `DisplayNotFoundError`: 显示器不存在
- `InvalidRegionError`: 区域参数非法
- `CaptureFailedError`: 截图失败（权限/驱动问题）

## 2. Vision Engine Module (视觉识别引擎)

### 职责
- OCR文字识别
- 图像轮廓匹配
- 颜色检测
- 组合条件判断

### 关键组件
```
VisionEngine/
├── ocr_engine.py            # PaddleOCR封装
├── template_matcher.py      # 模板匹配
├── color_detector.py        # 颜色检测
├── condition_evaluator.py   # 多条件组合判断
└── models/                  # OCR模型文件
    └── paddleocr_*.onnx
```

### 核心功能
#### 2.1 OCR识别
```python
def recognize_text(image: np.ndarray, language: str = 'multi') -> List[TextResult]

@dataclass
class TextResult:
    text: str               # 识别文本
    confidence: float       # 置信度 0-1
    bbox: List[Point]       # 四边形边界框
    language: str           # 检测到的语言
```
- **模型**: PaddleOCR v4 多语言模型
- **支持语言**: 中文、英文、日文、韩文、数字、符号
- **性能**: 单次识别 < 500ms（CPU）

#### 2.2 轮廓匹配
```python
def match_template(source: np.ndarray, template: np.ndarray, 
                   threshold: float = 0.85) -> List[MatchResult]

@dataclass
class MatchResult:
    x: int                  # 匹配位置
    y: int
    width: int
    height: int
    confidence: float       # 相似度 0-1
```
- **算法**: TM_CCOEFF_NORMED
- **容差**: 支持轻微缩放（±5%）
- **多匹配**: 返回所有 >= threshold 的结果

#### 2.3 颜色检测
```python
def detect_color(image: np.ndarray, target_color: Color, 
                 tolerance: ColorTolerance) -> List[ColorMatch]

@dataclass
class Color:
    r: int  # 0-255
    g: int
    b: int
    # 或
    h: float  # 0-360
    s: float  # 0-100
    v: float  # 0-100

@dataclass
class ColorTolerance:
    rgb_tolerance: int = 15      # 每通道±15
    hsv_tolerance: Tuple[float, float, float] = (10, 20, 20)

@dataclass
class ColorMatch:
    x: int
    y: int
    pixel_count: int        # 匹配像素数
    percentage: float       # 占比
```

#### 2.4 组合条件判断
```python
def evaluate_conditions(image: np.ndarray, 
                        conditions: List[Condition]) -> bool

class Condition:
    type: ConditionType  # OCR | TEMPLATE | COLOR
    operator: Operator   # AND | OR
    params: Dict[str, Any]
```
- **逻辑**: 按序执行，支持短路求值
- **示例**: (颜色匹配 AND 文字="开始") OR 模板匹配

### 性能优化
- **ROI优先**: 优先处理感兴趣区域
- **缓存模板**: 模板特征向量缓存
- **多线程**: OCR和模板匹配可并行

## 3. Target Manager Module (目标管理模块)

### 职责
- 目标的增删改查
- 目标分组管理
- 目标图片存储
- 数据持久化（JSON → SQLite）

### 关键组件
```
TargetManager/
├── target_storage.py        # 存储抽象层
├── json_storage.py          # JSON实现
├── sqlite_storage.py        # SQLite实现（预留）
├── target_model.py          # 数据模型
└── migration.py             # 数据迁移工具
```

### 核心功能
#### 3.1 目标创建
```python
def create_target(data: TargetCreateRequest) -> Target

@dataclass
class TargetCreateRequest:
    name: str
    group_id: Optional[str]
    image: np.ndarray               # 原始截图
    save_compressed: bool = False   # 是否压缩
    conditions: List[RecognitionCondition]
```

#### 3.2 目标查询
```python
def get_target(target_id: str) -> Target
def list_targets(group_id: Optional[str] = None) -> List[Target]
def search_targets(keyword: str) -> List[Target]
```

#### 3.3 分组管理
```python
def create_group(name: str, parent_id: Optional[str] = None) -> Group
def move_to_group(target_id: str, group_id: str) -> None
def delete_group(group_id: str, cascade: bool = False) -> None
```

### 数据模型
```python
@dataclass
class Target:
    id: str                     # UUID
    name: str
    group_id: Optional[str]
    image_path: str             # 相对路径
    thumbnail_path: str         # 缩略图路径
    created_at: datetime
    updated_at: datetime
    conditions: List[RecognitionCondition]
    metadata: Dict[str, Any]    # 扩展字段

@dataclass
class RecognitionCondition:
    type: ConditionType         # OCR | TEMPLATE | COLOR
    operator: Operator          # AND | OR (与下一条件)
    params: Dict[str, Any]
    # OCR params: {"text": "开始", "fuzzy": false}
    # TEMPLATE params: {"threshold": 0.85}
    # COLOR params: {"color": {...}, "tolerance": {...}}

@dataclass
class Group:
    id: str
    name: str
    parent_id: Optional[str]
    target_count: int
    created_at: datetime
```

### 存储结构
```
data/
├── targets.json             # 目标元数据
├── groups.json              # 分组信息
└── images/
    ├── full/                # 原图
    │   └── {target_id}.png
    ├── compressed/          # 压缩图
    │   └── {target_id}.png
    └── thumbnails/          # 缩略图
        └── {target_id}_thumb.png
```

### 迁移设计
```python
# 预留接口，便于未来迁移到SQLite
class StorageBackend(ABC):
    @abstractmethod
    def save_target(self, target: Target) -> None
    @abstractmethod
    def load_target(self, target_id: str) -> Target
    # ...
```

## 4. Script Engine Module (脚本引擎模块)

### 职责
- Lua脚本解析和执行
- 提供API调用视觉识别和输入模拟
- 脚本间调用管理
- 执行流程控制

### 关键组件
```
ScriptEngine/
├── lua_vm.py                # Lua虚拟机封装
├── script_api.py            # 暴露给Lua的API
├── execution_controller.py  # 执行控制器
└── script_loader.py         # 脚本加载器
```

### 核心功能
#### 4.1 脚本执行
```python
def execute_script(script_path: str, args: Dict[str, Any], 
                   mode: ExecutionMode) -> ExecutionResult

class ExecutionMode(Enum):
    NORMAL = "normal"            # 正常执行
    STEP = "step"                # 单步模式
    RUN_ONCE = "run_once"        # 执行一次
    LOOP_N_TIMES = "loop_n"      # 循环N次
    LOOP_UNTIL_STOP = "loop_until_stop"  # 永久循环
    LOOP_UNTIL_TARGET = "loop_until_target"  # 检测到目标停止

@dataclass
class ExecutionResult:
    success: bool
    output: Any                  # 脚本返回值
    logs: List[str]
    execution_time: float
    error: Optional[str]
```

#### 4.2 脚本互调
```python
# 在Lua中调用
result = call_script("script_b.lua", {input = 123})
```
- **传参**: JSON序列化传递
- **返回值**: JSON反序列化
- **错误处理**: 子脚本错误不中断父脚本

#### 4.3 执行控制
```python
def pause_execution() -> None
def resume_execution() -> None
def stop_execution() -> None
def get_execution_state() -> ExecutionState

@dataclass
class ExecutionState:
    is_running: bool
    is_paused: bool
    current_line: int
    current_script: str
    variables: Dict[str, Any]
```

### Lua API设计
详见 `04-Lua脚本API.md`，核心API包括：
- `wait_for_target(target_id)` - 等待目标出现
- `click(x, y)` - 鼠标点击
- `type_text(text)` - 输入文字
- `get_ocr_text(region)` - 获取OCR文本
- `call_script(path, args)` - 调用其他脚本

## 5. Input Simulator Module (输入模拟模块)

### 职责
- 模拟鼠标移动、点击、滚轮
- 模拟键盘按键、组合键
- 支持区域限定

### 关键组件
```
InputSimulator/
├── mouse_controller.py      # 鼠标控制
├── keyboard_controller.py   # 键盘控制
└── region_limiter.py        # 区域限制器
```

### 核心功能
#### 5.1 鼠标操作
```python
def move_mouse(x: int, y: int, duration: float = 0) -> None
def click_mouse(x: int, y: int, button: MouseButton = LEFT) -> None
def double_click(x: int, y: int) -> None
def scroll(delta: int) -> None

class MouseButton(Enum):
    LEFT = "left"
    RIGHT = "right"
    MIDDLE = "middle"
```
- **平滑移动**: duration > 0 时贝塞尔曲线插值
- **区域限制**: 检查坐标是否在限定区域内

#### 5.2 键盘操作
```python
def press_key(key: str) -> None
def release_key(key: str) -> None
def type_text(text: str, interval: float = 0.05) -> None
def press_hotkey(*keys: str) -> None
```
- **按键名称**: 支持 "a"、"ctrl"、"F1"、"enter" 等
- **组合键**: `press_hotkey("ctrl", "c")`

#### 5.3 区域限定
```python
def set_region_limit(region: Optional[Region]) -> None
def check_point_in_region(x: int, y: int) -> bool

@dataclass
class Region:
    x: int
    y: int
    width: int
    height: int
    allow_exit: bool = True  # 是否允许鼠标移出
```

## 6. Window Manager Module (窗口管理模块)

### 职责
- 枚举系统窗口
- 获取窗口信息
- 绑定目标窗口
- 窗口状态监控

### 关键组件
```
WindowManager/
├── window_enum.py           # 窗口枚举
├── window_info.py           # 窗口信息获取
└── window_binder.py         # 窗口绑定
```

### 核心功能
#### 6.1 窗口枚举
```python
def list_windows() -> List[WindowInfo]

@dataclass
class WindowInfo:
    handle: int              # HWND
    title: str
    class_name: str
    process_id: int
    process_name: str
    rect: Rect               # 窗口位置
    is_visible: bool
    is_minimized: bool
```

#### 6.2 窗口绑定
```python
def bind_window(handle: int) -> None
def get_bound_window() -> Optional[WindowInfo]
def unbind_window() -> None
```
- **绑定后行为**: 所有截图和输入操作限定在该窗口客户区

#### 6.3 窗口监控
```python
def watch_window(handle: int, callback: Callable) -> None
```
- **监控事件**: 窗口关闭、最小化、失去焦点

## 8. IPC Bridge Module (前后端桥接模块)

### 职责
- Tauri命令处理
- 事件通知（后端 → 前端）
- 数据序列化
- 错误统一处理

### 关键组件
```
IPCBridge/
├── command_handler.py       # 命令处理器
├── event_emitter.py         # 事件发射器
└── serializer.py            # 序列化工具
```

### 核心功能
#### 8.1 命令处理
```python
@ipc_command
def handle_create_target(data: dict) -> dict:
    # 1. 解析参数
    # 2. 调用 TargetManager
    # 3. 返回结果
    pass
```

#### 8.2 事件通知
```python
def emit_event(event_name: str, payload: dict) -> None

# 示例事件
emit_event("script_started", {"script_id": "xxx"})
emit_event("target_detected", {"target_id": "yyy", "position": {...}})
emit_event("execution_paused", {"line": 15, "variables": {...}})
```

### 命令清单
详见 `03-IPC协议.md`，包括：
- `capture_screen` - 截图
- `create_target` - 创建目标
- `execute_script` - 执行脚本
- `set_breakpoint` - 设置断点
- ...（约50个命令）
