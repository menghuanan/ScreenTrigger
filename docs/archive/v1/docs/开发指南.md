## 4. 模块实现指南

### 4.1 IPC 通信实现

#### Python 端 (backend/ipc_bridge.py)
```python
import sys
import json

class IPCBridge:
    def __init__(self):
        self.handlers = {}
    
    def register_handler(self, command: str, handler):
        self.handlers[command] = handler
    
    def start(self):
        while True:
            line = sys.stdin.readline()
            if not line:
                break
            
            try:
                request = json.loads(line)
                response = self.handle_request(request)
            except Exception as e:
                response = self.error_response(1002, str(e))
            
            self.send_response(response)
    
    def handle_request(self, request):
        command = request.get('command')
        params = request.get('params', {})
        
        handler = self.handlers.get(command)
        if not handler:
            return self.error_response(1003, f"Unknown command: {command}")
        
        try:
            result = handler(params)
            return self.success_response(result)
        except Exception as e:
            return self.error_response(1002, str(e))
    
    def send_response(self, response):
        sys.stdout.write(json.dumps(response) + '\n')
        sys.stdout.flush()
    
    def emit_event(self, event_name: str, payload: dict):
        event = {
            'type': 'event',
            'name': event_name,
            'payload': payload
        }
        sys.stdout.write('EVENT:' + json.dumps(event) + '\n')
        sys.stdout.flush()
    
    @staticmethod
    def success_response(data):
        return {'success': True, 'data': data}
    
    @staticmethod
    def error_response(code: int, message: str):
        return {
            'success': False,
            'error': {'code': code, 'message': message}
        }
```

## 6. 常见问题

### 6.1 DPI 缩放导致坐标偏移
**解决方案**：参考 `07-实现细节清单.md` 第1节的 DPI 适配方案

### 6.2 OCR 识别不准确
**解决方案**：
- 检查图片质量
- 调整 min_confidence 参数
- 预处理图像（二值化、降噪）

### 6.3 Lua 脚本执行慢
**解决方案**：
- 使用识别缓存
- 降低识别频率
- 优化循环逻辑

### 6.4 内存占用过高
**解决方案**：
- 实现图像缓存 LRU
- 及时释放大对象
- 使用内存池

### 7.2 TypeScript
- 遵循 Airbnb Style Guide
- 使用接口定义数据结构
- 组件使用函数式写法

```typescript

  name: string;
  groupId?: string;
```

### 7.3 Lua
- 使用 snake_case 命名
- 缩进 2 空格
- 添加注释说明

```lua
-- 等待目标出现并点击
function wait_and_click(target_id, timeout)
  local found, pos = wait_for_target(target_id, timeout)
  if found then
    click_at(pos.x, pos.y)
    return true
  end
  return false
end
```
