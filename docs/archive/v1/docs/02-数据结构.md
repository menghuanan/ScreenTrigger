```json
      "is_compressed": false,

      "conditions": [
        {
          "type": "template",
          "operator": "and",
          "params": {
            "threshold": 0.85,
            "region": null
          }

        {
```

### 1.2 条件类型定义

#### Template Condition (模板匹配)
```json
{
  "type": "template",
  "operator": "and",
  "params": {
    "threshold": 0.85,
    "region": {
      "x": 100,
      "y": 100,
      "width": 200,
      "height": 150
    },
    "allow_scale": false,
    "scale_range": [0.95, 1.05]
  }
}
```

#### OCR Condition (文字识别)
```json
{
  "type": "ocr",
  "operator": "and",
  "params": {
    "text": "开始游戏",
    "fuzzy_match": true,
    "fuzzy_threshold": 0.8,
    "min_confidence": 0.75,
    "language": "multi",
    "region": null,
    "case_sensitive": false
  }
}
```

#### Color Condition (颜色检测)
```json
{
  "type": "color",
  "operator": "and",
  "params": {
    "color_space": "rgb",
    "color": {
      "r": 59,
      "g": 109,
      "b": 255
    },
    "tolerance": {
      "r": 15,
      "g": 15,
      "b": 15
    },
    "min_pixel_count": 100,
    "min_percentage": 5.0,
    "region": null
  }
}
```

#### Color Condition (HSV模式)
```json
{
  "type": "color",
  "operator": "and",
  "params": {
    "color_space": "hsv",
    "color": {
      "h": 220,
      "s": 75,
      "v": 100
    },
    "tolerance": {
      "h": 10,
      "s": 20,
      "v": 20
    },
    "min_pixel_count": 50,
    "region": {
      "x": 0,
      "y": 0,
      "width": 100,
      "height": 100
    }
  }
}
```

### 1.3 条件运算符
- `"and"`: 与下一个条件进行 AND 运算
- `"or"`: 与下一个条件进行 OR 运算
- `null`: 最后一个条件（无后续运算）

### 1.4 Region 通用结构
```json
{
  "x": 100,
  "y": 100,
  "width": 200,
  "height": 150,
  "display_index": 0
}
```
- `null` 表示全屏范围


### 2.2 分组层级关系
- **最大深度**: 3层（避免过度嵌套）
- **根分组**: `parent_id` 为 `null`
- **删除策略**: 
  - `cascade=true`: 删除所有子分组和目标
  - `cascade=false`: 子分组提升到父级，目标移至"未分组"

### 4.2 配置项说明

#### Recognition 配置
- `frequency.default_fps`: 默认识别频率（次/秒）
- `ocr.use_gpu`: 是否使用GPU加速（需要CUDA）
- `template.allow_scale`: 是否允许缩放匹配

#### Input 配置
- `mouse.move_duration`: 鼠标移动动画时长（秒）
- `keyboard.type_interval`: 输入字符间隔（秒）

#### Capture 配置
- `min_region_size`: 最小截图区域 [宽, 高]
- `compression_quality`: 压缩图片质量 (1-100)

## 6. 数据库Schema（预留）

### 6.1 SQLite表结构

#### targets 表
```sql
CREATE TABLE targets (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    group_id TEXT,
    image_path TEXT NOT NULL,
    thumbnail_path TEXT,
    is_compressed INTEGER DEFAULT 0,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    conditions TEXT NOT NULL,  -- JSON字符串
    metadata TEXT,             -- JSON字符串
    FOREIGN KEY (group_id) REFERENCES groups(id) ON DELETE SET NULL
);

CREATE INDEX idx_targets_group ON targets(group_id);
CREATE INDEX idx_targets_name ON targets(name);
CREATE INDEX idx_targets_created ON targets(created_at);
```

#### groups 表
```sql
CREATE TABLE groups (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    parent_id TEXT,
    color TEXT,
    icon TEXT,
    created_at TEXT NOT NULL,
    metadata TEXT,
    FOREIGN KEY (parent_id) REFERENCES groups(id) ON DELETE CASCADE
);

CREATE INDEX idx_groups_parent ON groups(parent_id);
```

#### scripts 表
```sql
CREATE TABLE scripts (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    file_path TEXT NOT NULL UNIQUE,
    description TEXT,
    author TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    tags TEXT,              -- JSON数组
    parameters TEXT,        -- JSON数组
    dependencies TEXT,      -- JSON数组
    metadata TEXT
);

CREATE INDEX idx_scripts_name ON scripts(name);
CREATE FULL TEXT INDEX idx_scripts_description ON scripts(description);
```

#### execution_history 表
```sql
CREATE TABLE execution_history (
    id TEXT PRIMARY KEY,
    script_id TEXT NOT NULL,
    start_time TEXT NOT NULL,
    end_time TEXT,
    status TEXT NOT NULL,  -- success | failed | stopped
    error_message TEXT,
    execution_time REAL,
    iterations INTEGER,
    metadata TEXT,
    FOREIGN KEY (script_id) REFERENCES scripts(id) ON DELETE CASCADE
);

CREATE INDEX idx_history_script ON execution_history(script_id);
CREATE INDEX idx_history_time ON execution_history(start_time);
```

## 7. 文件路径约定

### 7.1 数据目录结构
```
E:\ScreenTrigger\
├── data\
│   ├── targets.json           # 目标元数据
│   ├── groups.json            # 分组信息
│   ├── config.json            # 用户配置
│   ├── images\
│   │   ├── full\              # 原图
│   │   │   └── {uuid}.png
│   │   ├── compressed\        # 压缩图
│   │   │   └── {uuid}.png
│   │   └── thumbnails\        # 缩略图 (200x200)
│   │       └── {uuid}_thumb.png
│   └── database\
│       └── screentrigger.db   # SQLite数据库（预留）
├── scripts\
│   ├── script_metadata.json   # 脚本元数据
│   └── *.lua                  # Lua脚本文件
├── logs\
│   ├── app.log                # 应用日志
│   └── execution\             # 执行日志
│       └── exec-{datetime}.log
└── temp\
    └── captures\              # 临时截图
        └── temp-{uuid}.png
```

### 7.2 路径处理规则
- **绝对路径**: 用于系统级操作（截图、窗口）
- **相对路径**: 数据文件内部引用（`images/full/xxx.png`）
- **路径分隔符**: Python统一使用 `/`，Tauri前端使用平台原生分隔符

## 9. 数据版本管理

### 9.1 版本号规则
使用语义化版本 `MAJOR.MINOR.PATCH`：
- **MAJOR**: 不兼容的数据结构变更
- **MINOR**: 向后兼容的功能新增
- **PATCH**: 向后兼容的问题修正

## 10. 性能优化建议

### 10.1 数据加载
- **懒加载**: 目标图片仅在需要时加载
- **缓存**: 常用目标的特征向量缓存在内存
- **索引**: JSON文件加载后建立内存索引

### 10.2 数据存储
- **批量写入**: 多个操作合并后统一写入
- **增量保存**: 仅保存变更的数据
- **压缩**: 大型JSON文件使用gzip压缩

### 10.3 图片存储
- **缩略图**: 200x200 JPEG 质量80
- **原图**: PNG无损格式
- **压缩图**: PNG 质量85（可选）
