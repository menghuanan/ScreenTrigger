## 🎯 如何使用这些文档

### 场景1：开始一个新模块
1. 阅读 `00-项目概览.md` 了解整体架构

## 🔧 技术栈速查

### 前端 (Tauri)
- **框架**: Tauri 2.x
- **UI**: React 18 / Vue 3（待选定）
- **语言**: TypeScript + Rust
- **构建**: Vite

### 后端 (Python)
- **版本**: Python 3.13.x
- **OCR**: PaddleOCR v4
- **图像**: OpenCV, PIL
- **脚本**: lupa (Lua for Python)
- **输入**: keyboard, pyautogui
- **窗口**: win32api, win32gui

### 数据存储
- **初期**: JSON 文件
- **后期**: SQLite 数据库

### 脚本语言
- **引擎**: Lua 5.4
- **特性**: 沙箱隔离、自定义 API

## 📝 文档维护规范

### 更新文档时的注意事项
1. **保持一致性**：修改一处时检查相关文档是否需要同步更新
2. **版本标记**：重大变更时更新版本号
3. **示例代码**：确保代码片段可以直接运行
4. **交叉引用**：使用相对链接关联相关文档

### 需要同步更新的关联
- 修改 IPC 命令 → 更新 `03-IPC协议.md` 和 `01-模块拆分.md`
- 新增 Lua API → 更新 `04-Lua脚本API.md` 和 `07-实现细节清单.md`
- 修改数据结构 → 更新 `02-数据结构.md` 和可能的流程图
- 新增错误码 → 更新 `03-IPC协议.md` 和 `06-边界条件与约束.md`
