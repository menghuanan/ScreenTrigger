# ScreenTrigger 项目概览

## 项目定位
一个基于视觉识别的桌面自动化工具，支持图像识别、OCR、颜色检测、脚本编写和输入模拟。

## 技术栈
- **前端框架**: Tauri 2.x + React 18 / Vue 3（待选定）
- **后端引擎**: Python 3.13.x
- **脚本语言**: Lua 5.4
- **图像识别**: PaddleOCR + OpenCV
- **目标平台**: Windows 10/11（初期）

## 核心功能
1. **屏幕捕获**: 支持全屏/区域/窗口截图，多显示器环境
2. **图像识别**: OCR（多语言）、轮廓匹配（85%默认相似度）、颜色检测（RGB/HSV）
3. **目标管理**: 打标、分组、多条件组合识别
4. **脚本引擎**: Lua脚本，支持调试（单步、断点、变量查看）
5. **输入模拟**: 键盘、鼠标模拟，支持区域限定
6. **窗口绑定**: 指定目标应用窗口执行脚本

## 数据流
1. **目标创建流程**: 用户框选 → 截图 → 识别 → 保存目标
2. **脚本执行流程**: 加载脚本 → 解析Lua → 循环检测目标 → 触发动作 → 输出结果
3. **调试流程**: 设置断点 → 单步执行 → 查看变量 → 继续/停止

## 开发优先级

## 关键约束
- **最小框选**: 10x10 像素
- **识别频率**: 1次/秒（默认），可调至5次/秒
- **OCR语言**: 全语言支持（中英日韩 + 符号）
- **相似度**: 85%（默认可调）
- **RGB容差**: ±15～20 / 通道
- **脚本权限**: 无文件系统/网络访问
- **DPI支持**: 100%～300% 缩放
