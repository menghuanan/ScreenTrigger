# ScreenTrigger

一个基于视觉识别的桌面自动化工具，支持图像识别、OCR、颜色检测、脚本编写和输入模拟。

## 项目状态

🚧 **开发中** - 设计文档已完成，代码实现进行中

## 功能特性

- 🖼️ **屏幕捕获** - 支持全屏/区域/窗口截图，多显示器环境
- 🔍 **图像识别** - OCR（多语言）、轮廓匹配、颜色检测
- 🎯 **目标管理** - 打标、分组、多条件组合识别
- 📜 **脚本引擎** - Lua脚本，支持调试（单步、断点、变量查看）
- ⌨️ **输入模拟** - 键盘、鼠标模拟，支持区域限定
- 🪟 **窗口绑定** - 指定目标应用窗口执行脚本

## 技术栈

- **前端**: Tauri 2.x + React/Vue
- **后端**: Python 3.13.x
- **脚本**: Lua 5.4
- **识别**: PaddleOCR + OpenCV
- **平台**: Windows 10/11（初期）

## 设计原则

1. **模块化** - 8个独立模块，职责单一，接口清晰
2. **可扩展** - JSON→SQLite 迁移路径，插件式架构
3. **高性能** - 缓存、并行、内存池优化
4. **易用性** - 简单的 Lua API，可视化调试
5. **安全性** - 沙箱隔离，路径验证，输入净化

## 关键约束

- **最小框选**: 10x10 像素
- **识别频率**: 1次/秒（默认），可调至5次/秒
- **脚本超时**: 3600 秒（1小时）
- **并发脚本**: 最多 3 个
- **目标数量**: 10000 个（JSON存储上限）

## 技术亮点

- ✅ DPI 自适应（支持 100%-300% 缩放）

## 示例脚本

### 自动登录
```lua
-- 等待登录按钮出现
local found, pos = wait_for_target("button-login", 30)
if found then
  click_target("button-login")
  wait(1)
  type_text(args.username)
  press_key("tab")
  type_text(args.password)
  press_key("enter")
  log("登录完成")
end
```

### 自动采集
```lua
local count = 0
while count < 10 do
  local found, positions = find_target("collect-icon")
  if found then
    for i, pos in ipairs(positions) do
      click_at(pos.x, pos.y)
      wait_random(0.3, 0.5)
      count = count + 1
    end
  else
    wait(5)
  end
end
log("采集完成，共 " .. count .. " 个")
```
