# 配置与故障排查

这是首版使用设计；实际字段见[配置规范](../02-数据结构.md)，错误码见[边界与约束](../06-边界条件与约束.md)。当前还没有安装包或已生成的用户配置。

## 常用配置

| 设置 | 默认 | 说明 |
|---|---|---|
| 识别频率 | 1Hz | 快捷选5，自定义建议0.1–30；显示实际Hz，超过能力不会加速OCR |
| 模板/轮廓阈值 | 0.85 | 创建新条件时使用；改设置不会重写现有目标 |
| RGB容差 | 各通道15 | 可改20或自定义；越宽越易误报 |
| HSV容差 | H=10°、S=20、V=20 | H使用环回；HSC含义还需确认 |
| OCR模型 | 未选择 | 选已安装模型后文字识别可用；语言覆盖由模型决定 |
| 允许移出区域 | 否 | 只限制程序模拟输入，不锁住真人鼠标 |
| 总执行期限 | 0（不限） | 单位在设置界面可显示秒；内部毫秒 |
| 监控等待期限 | 30秒 | 与总期限不同；可有限重试或超时脚本 |
| PNG压缩 | 级别6 | 无损且不缩放；不能用“质量85”理解 |
| 快捷键 | Ctrl+Alt+S/X/P | 框选/停止/暂停恢复；系统冲突需换组合 |
| 日志 | info，10MiB×5 | 普通运行不弹实时日志窗；结束后可主动查看 |

运行设置优先于全局默认；运行中的配置采用启动快照，新设置通常对下一次执行生效。热键立即生效，模型目录调整需要重新初始化。更新失败保留旧设置；“恢复默认”不删除目标和脚本。

## 数据位置和备份

预期数据根 `%LOCALAPPDATA%/ScreenTrigger/`，设置页面显示真实路径。内含配置、目标/组/脚本索引、原图、脚本源码、模型与历史日志。不要只备份一个targets.json；应在无活动执行时备份完整数据目录，保留current指针指向的generation和图片/源码资产。

首版不保存临时区域或窗口绑定为工作区。执行历史可含当次区域用于诊断，但不能直接复用成下一次任务。

手工编辑配置前退出应用并备份。损坏文件不要删掉当恢复办法；启动应提示可用备份，用户选择恢复，原损坏文件保留供排查。数据版本高于软件时升级软件，不手动降低schema_version。

## 故障定位

| 现象 | 原因/检查 | 恢复方式 |
|---|---|---|
| 没找到目标 | 场景变了、阈值高、ROI不含目标 | 先测试识别，检查候选框和原图，再调条件 |
| OCR不可用 | 模型没选/缺失、依赖故障 | 检查模型列表/校验信息；无网络时导入离线包；纯脚本仍可用 |
| 某种语言/符号不识别 | 当前模型不覆盖或图片质量不足 | 选择覆盖该语言模型，放大显示/重选；不保证全部Unicode |
| 设置5Hz实际只有1Hz | 单次推理耗时高 | 缩小ROI、降低请求频率或评估其他模型；系统跳过过期tick |
| 点击被拒绝 | 位置/路径越界、窗口身份或几何变了 | 检查区域和前台窗口，重新识别，不随意重复发点击 |
| 窗口最小化后停住 | 窗口不可操作 | 恢复并置前台，再手动继续 |
| 窗口关闭后无法继续 | 原绑定身份已失效 | 重新选择窗口，启动新执行；不自动找同名窗口 |
| 坐标偏移 | DPI或旧窗口位置；误把bbox角当中心 | 重选区域，使用click_target；保存显示器与DPI信息反馈 |
| 框选失败/画面递归 | 捕获/覆盖层排除不兼容 | 取消并确认主窗口恢复，记录OS/屏幕信息；不是正常功能 |
| 快捷键不能注册 | 被系统/其他应用占用 | 更换设置；停止入口未就绪时不启动输入任务 |
| 保存失败 | 磁盘空间、文件占用或冲突revision | 释放空间/关闭占用后重试；冲突先重载合并；旧数据仍有效 |
| 请求超时但可能已执行 | 响应丢失或后台慢 | 查执行状态/目标revision；检查目标应用，不盲目重新运行 |
| 引擎退出 | Python/OCR/Lua worker异常 | 查看诊断后重启引擎；之前任务不自动续跑 |
| 子脚本返回值错误 | 返回函数、稀疏/循环table等 | 改成普通JSON值，数组/空值按Lua教程表示 |

普通运行不显示日志窗口不代表没有记录。需要排查时主动打开历史结果；调试暂停时再查看变量和详细日志。默认不保存输入文本全文或截图；不要在显式log中写入不希望保留的内容。
