# 用户指南

本地 Windows x64 候选的安装、升级、数据目录选择和卸载见[离线安装](离线安装.md)。正式发布状态以绑定安装包哈希的 release 审计为准。

## 安装候选版

1. 取得维护人员提供的 Windows x64 候选 ZIP 及其 SHA-256，核对哈希后完整解压。构建和安装命令见[离线安装](离线安装.md)。
2. 运行离线包内的安装脚本，通过开始菜单打开应用。Windows App SDK、.NET、Python 引擎和已选离线模型由同一安装包提供。
3. 首次启动时在「引擎」页检查“引擎就绪”，点击「查看 OCR 模型」。缺少权重时，先用纯脚本验证引擎，再核对安装介质与模型清单。当前候选的模型目录设置与实际装载路径仍有差异，见[配置与故障排查](配置与故障排查.md)。
4. 检查停止快捷键是否注册成功。默认Ctrl+Alt+X；冲突时在设置中更换。确认状态后再开始输入型任务。

RC11 的 ZIP 为 568,236,136 字节。安装另需解压和运行空间；磁盘与内存最低要求仍待测量。卸载默认保留用户数据，需要清空时按[卸载步骤](离线安装.md)指定数据根。

## 第一个目标

1. 打开「截图与导入」，点击「导入图片」选择本地 PNG/JPEG，或点击「框选屏幕」。默认框选快捷键为 Ctrl+Alt+S。
2. 框选时主窗口立即隐藏；默认在主窗口所在显示器，拖动会显示实时预览和物理坐标。至少10×10像素；Esc取消，结束后自动恢复窗口。
3. 切到「目标库」，点击「新建目标」，填写名称并选择分组。当前面板用 JSON 编辑条件，初始模板阈值为 0.85。模板、轮廓、文字和颜色条件可围绕同一候选框组合。
4. 点击「测试当前草稿」，在「测试识别」页点「测试当前图片」，查看匹配框、分数及逐条件证据。
5. 回到「目标库」，点「保存目标」，记下稳定的目标 ID 和样本编号。脚本按 ID 引用目标，后续可以改名。退出主窗口前先保存目标或脚本草稿。

10×10只是允许选取的下限，小文字不保证识别准确。OCR能识别什么取决于已装模型；列表没有的语言或特殊符号不能保证识别。

## 运行脚本

在脚本编辑器创建并保存Lua脚本，参考[脚本入门](脚本入门.md)。选择一次、N次、持续运行或检测目标后停止。纯脚本无需创建识别目标。

运行前选定显示器或已打开的应用窗口，也可以框选本次识别区域。选择“限制在区域内”时程序模拟的鼠标不得越界；允许移出时识别仍只看区域内。绑定窗口始终限制输入在客户区；键盘发送到绑定的前台窗口，键盘操作的业务影响不能按像素区域裁剪。

区域与窗口只用于本次会话，不保存为工作区。重新打开应用需要重选。首版最多同时运行三个根任务，每根独立持有输入租约。子脚本可同步调用。

普通运行只显示状态、暂停/停止入口，不弹实时日志。按Ctrl+Alt+X停止，Ctrl+Alt+P暂停/恢复。界面显示停止后，不再发送新输入，但已经送到外部应用的点击无法撤回。

## 区域监控

新建临时监控 → 选区域/窗口 → 选目标 → 设频率（默认1次/秒，可5次或更高）→ 选命中后停止或运行脚本 → 设等待超时行为 → 开始。

默认等待30秒，超时停止；可设有限重试或运行一次失败脚本。默认持续出现同一目标只触发第一次，目标消失后再次出现才触发；选择每次命中模式后仍需等动作完成及冷却。频率高于电脑实际处理能力时会显示实际频率，不积压旧识别结果。

识别错误与未找到目标不同。模型缺失、推理故障不会被当成超时去点击别处；取消也不会运行失败脚本。成功动作接收 args.match，包含样本号和坐标；教程有示例。

## 调试

在可执行行设置断点，选择调试运行。命中断点或单步时显示变量、调用栈和日志。进入/越过/跳出分别控制函数与子脚本边界；变量只读。修改源码后重新校验断点。继续时先检查目标窗口仍在前台。

窗口失焦/最小化时自动暂停输入，用户恢复窗口后手动继续；窗口关闭则本次执行终止，需重选新运行。不要期待后台或被遮挡窗口仍可靠接受输入。

配置项、数据保存位置和恢复方法见[配置与故障排查](配置与故障排查.md)。
