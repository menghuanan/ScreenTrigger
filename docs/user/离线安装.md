# Windows x64 离线安装

拿到候选 ZIP 和该候选的 SHA-256 后，用 `Get-FileHash -Algorithm SHA256` 核对 ZIP，完整解压到较短的本地目录。在解压目录打开 PowerShell，运行以下命令。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
```

安装程序逐文件校验清单，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ScreenTrigger`，并创建开始菜单的 ScreenTrigger 快捷方式。该快捷方式启动 WinUI 3 的 `ScreenTrigger.exe`。程序随附 x64 .NET 10、Windows App SDK、VC 运行库、Rust 宿主、CPython 3.13、Lua 5.4 和目录中已核对的 OCR 模型。模型卡、逐文件哈希和第三方许可随包保存。

升级前退出应用。安装程序检查 `%LOCALAPPDATA%\ScreenTrigger`、旧应用标识目录 `%LOCALAPPDATA%\com.screentrigger.app` 和上次安装所选目录。只有一份有效旧数据时继续使用它。发现多份时显示路径和记录数，在切换前备份。曾显式指定其他路径的用户可以向安装命令传 `-DataRoot "D:\我的数据\ScreenTrigger"`。数据校验失败时按提示检查原目录。设置页显示运行中的数据路径。

卸载前退出应用。在已安装的 `ScreenTrigger.exe` 旁运行 `Uninstall.ps1`，默认保留数据、备份和历史。确实要一并删除时，传入 `-DeleteDataRoot` 和设置页显示的完整目录。目录内存在其他文件时需自行核实归属。

构建端使用[用户端 Offline 发布配置](../../desktop/ScreenTrigger.User/Properties/PublishProfiles/Offline.pubxml)、[引擎 wheel 锁](../../manifest/release-cp313-win-x64.txt)及[介质构建脚本](../../tools/packaging/build_offline.py)。在项目的 CPython 3.13.14 x64 环境执行。输出名称每批唯一。

```powershell
dotnet publish desktop/ScreenTrigger.User/ScreenTrigger.User.csproj -c Release -p:PublishProfile=Offline -p:RestoreLockedMode=true -o dist/p3/ui
.\.venv\Scripts\python.exe tools/packaging/build_offline.py --crt "C:\Program Files\Microsoft Visual Studio\18\Community\VC\Redist\MSVC\14.52.37025\x64\Microsoft.VC145.CRT" --out dist/p3/ScreenTrigger-x64.zip
```

构建机可用 `--cpython`、`--wheels`、`--models`、`--nuget` 和 `--cargo` 指定本地介质及缓存。构建时由包内 Python 加载本地 OCR 权重，预编译首次启动所需的模块。源码与字节码逐文件列入安装清单。目标机的安装脚本只读取解压后的文件。正式支持的具体 Windows build 和性能以同一候选的实测回执为准。

## 备份与恢复

在设置页展开目标库备份，点击创建备份。选择备份后先查看恢复预览，再确认或取消。确认恢复会先保护当前记录和新写入的图像、脚本，随后切换到恢复的 generation。预览后发生写入时，须重新预览。设置、执行历史和日志属于各自的数据文件。移动整台机器的数据前请先退出应用，复制整个数据目录。

主窗口无法打开时，可在安装版本目录用自带 Python 操作同一数据根。先退出应用，替换下面的路径和备份 ID。预览返回的两个指纹用于确认恢复。

```powershell
.\resources\python\python.exe -I -B -m backend.storage.backup --data-dir "D:\我的数据\ScreenTrigger" list
.\resources\python\python.exe -I -B -m backend.storage.backup --data-dir "D:\我的数据\ScreenTrigger" create
```
