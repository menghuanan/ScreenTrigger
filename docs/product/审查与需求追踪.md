审查对象为重构前 11 份文档，保存在 [归档](../archive/README.md)。下表的原稿判断反映历史审查时点。当前仓库已有业务实现，现行桌面选型和可达入口见[WinUI 3 迁移设计](../winui3-migration.md)。以下“补齐”指文档定义完成，不表示软件功能已实现。

| 6. 按读者拆分 | 原目录混合产品、选型、代码片段；缺普通用户入口 | product/、decisions/、agent/、user/；00–07 作为技术规范 |

## 原稿关键矛盾及处理

| 原稿位置/问题 | 处理 |
|---|---|
| README/00/02 把识别上限定为 5Hz；用户允许更高 | 默认 1、快捷 5、自定义更高；建议 30Hz 上限，实际 Hz 明示 |
| README/06 一小时上限与永久循环冲突 | forever 默认无总期限，显式配置才限时 |
| 06 拒绝负坐标却声称多屏 | 物理虚拟屏幕坐标可负，验证显示器覆盖而不是 x≥0 |
| 01/06 有的自动裁剪，有的报错 | UI 限定拖选，API 非法区域/输入整笔拒绝，不钳制 |
| 07 Lua 初始化禁用 debug，稍后又 debug.sethook | 由宿主私有控制 hooks，脚本只见受限环境 |
| 开发指南锁 PaddleOCR 2.7，索引写 v4，Python 3.13 未验 | 移除未经验证安装承诺，增加兼容性探针与锁版本产物 |
| OCR lang='ch' 示例却称全语言 | 明确语言模型清单、覆盖与缺模型错误 |
| 轮廓能力仅用 TM_CCOEFF_NORMED 代替 | 分开 template 与 contour Provider，独立标定/验收 |
| 子脚本“错误不中断父脚本”缺错误协议 | 普通错误默认传播，可 pcall；取消不可绕过 |
| “不需要沙箱”与“安全沙箱隔离” | 不做恶意代码沙箱；保留无文件/网络的 API 能力约束 |
| PNG 压缩 quality=85 并缩放 | 无损压缩级别 0–9，不缩放原图；缩略图单列 |
| 03/开发指南无关联 ID 且同步循环阻塞停止 | 全双工 NDJSON、关联 ID、异步受理、输入闸门 |
| 170+ 函数、50+ API、完整且可复制等宣称 | 以接口契约和测试证据替代数量营销；原稿保留可追溯 |
