# 功能规格

范围：首版 Windows 本地应用。所有以下默认行为均为本轮建议基线；用户已明确要求的行为标注“已确认”。字段以 [02](../02-数据结构.md) 为准，错误见 [06](../06-边界条件与约束.md)。

## 通用交互

主窗、独立框选窗、应用对话框和以下各页全部使用 WinUI 3 原生控件，编辑器和预览也计入验收。系统文件选择器由应用窗口发起。逐项归属见[全前端迁移设计](../winui3-migration.md)。

主界面分为目标库、脚本编辑器、运行设置、设置页；调试时展开变量/调用栈/日志面板。顶栏始终显示引擎状态、当前执行状态、暂停及停止。所有长操作可取消，按钮禁用必须说明原因。未保存编辑在退出/切换时提示保存、放弃、取消；不会默默覆盖用户输入。

“未命中”是有效识别结果，不是引擎故障；“停止/取消”也不是识别失败。应用记录执行日志，但普通运行不展示实时日志窗口（已确认）。结束后允许主动打开历史结果。错误以状态栏或提示说明，不因普通日志自动弹窗。

## F01 屏幕框选与图片导入

**前置**：引擎就绪，未有框选会话；运行期间开始框选先请求暂停并等待输入释放。已有调试暂停保持原状态。

**正常**：用户点击框选或 Ctrl+Alt+S → 确定主窗口占面积最大的显示器（相等时取窗口中心所在屏；仍相等取系统主屏）→ 瞬间隐藏主窗口 → 等待隐藏完成 → 打开覆盖层 → 实时截取干净桌面帧并显示拖选 ROI 预览、物理坐标、宽高 → 松开鼠标后确认 → 返回 Region 与 ImageRef → 关闭覆盖层并自动恢复主窗口。取消也恢复；框选结束不会自动恢复刚暂停的输入脚本。

已确认：实时预览、默认主窗口所在显示器、最小 10×10 物理像素、坐标尺寸显示、瞬间隐藏和结束后恢复。建议预览 10Hz；坐标随指针更新，不等待 OCR。预览是持续采集的裁剪图，不只是在静态截图上画框。隔离覆盖层避免截图递归；不可实现干净捕获时不能悄悄退化为静态预览。

边界：反向拖动归一化；9×10 不可确认，10×10 可确认但不保证文字可识别；负虚拟屏幕坐标合法。一次框选限一块显示器，用户可在开始前切换显示器；不拼接跨屏选区。区域必须完全落在选定显示器，拖拽 UI 限制边界，API 越界拒绝，不自动裁剪。

异常/误操作：重复框选返回 BUSY；显示器拔除、权限阻断、捕获失败则结束会话并恢复主窗口，不保存目标。导入仅 PNG/JPEG，解码失败、超大小/像素预算、伪装扩展名均拒绝并保留编辑草稿。导入后可裁剪本地图像，与屏幕坐标不混用。

超时/重试/取消：隐藏或捕获准备 5s 超时；框选等待用户不设总时限。Esc、取消按钮均丢弃临时图，保留原目标；瞬时捕获错误只自动重试一次（200ms），最终失败由用户重试整个会话。临时图引用会话结束后释放，确认图进入编辑暂存区，10 分钟无操作过期会明确要求重新选取。

## F02 目标与分组

**正常**：导入/框选 → 填名称与可选分组 → 添加识别条件 → 测试识别 → 保存。保存后分配不可变 target_id 和单调递增、不重用的 sample_no；识别结果总是输出两者。名称可改，不影响脚本引用。

原图默认保留：导入保留原字节；屏幕原图为无缩放 PNG。可选无损 PNG 重编码，压缩级别不影响像素、尺寸；缩略图仅用于展示，不用于识别。条件至少一条；默认模板阈值 0.85 可调整。颜色容差默认每通道 ±15，可选 ±20 或自定义。

用户可创建/改名/移动分组。层级分组最多 3 层（已确认，与 02 一致）；删除分组把成员移到未分组，界面预先说明，不级联删目标。运行中的目标/脚本用启动时固定版本；修改仅影响下一次执行。正在被活动执行引用的目标不得删除；非活动脚本引用可提示影响但不改写脚本。

异常/边界：空名称、重复 sample_no、失效分组、条件为空或超 10 个、图片缺失拒绝保存；同名目标允许，用编号区分。版本冲突要求重新加载合并。落盘失败保留草稿与旧版本，不能返回保存成功。取消编辑丢弃本次草稿，不改变库。保存 5s 后状态未知时查询 revision，禁止盲目重复创建；去重规则见 IPC。

## F03 识别与复合条件

输入是 ImageRef 或当前运行的有效区域；输出 RecognitionResult，含 matches、样本号、原始 OCR 文本、置信度及各条件证据。OCR 尽量识别已装模型覆盖的语言、数字和符号；展示实际覆盖，不以 `multi` 暗示全字符支持。未知语言/缺模型报明确能力错误，不默默换模型或联网下载。

模板与轮廓是不同算法：模板处理像素相似，轮廓处理形状相近；用户在测试界面查看匹配框、分数并调阈值。颜色支持 RGB 与 HSV；DEC-001 已确认颜色模型为 HSV。

复合条件采用候选框锚点：先按 anchor 条件生成候选，再在各候选局部 ROI 上判断 AND/OR 树；避免屏幕左侧颜色与右侧文字被误算成同一目标。首版没有 NOT，防止无定位依据的“未出现”变成可点击目标。所有子条件共享同一帧和坐标版本。排序按 confidence 降序，再 y/x 升序；多结果默认动作只取首个。

未命中：返回 `found=false, matches=[]`；普通 OCR 无字返回空 blocks。服务错误、推理超时 5s、缺模型均作为错误，不转换成未命中。测试按钮只识别和显示结果，不点击。取消后丢弃迟到结果；不再派发动作。OCR 微小文字只提示可能低准确率，不因低于某字高直接拒绝。

## F04 区域监控（完整用例）

用户可以：①创建临时监控区域；②设置检测频率；③选择目标和条件；④设置命中后动作；⑤设置未命中与错误行为。监控不是后台永久服务，关闭应用即终止，区域不保存复用。

配置：Region、可选窗口绑定、target_id、frequency_hz（默认 1，快捷 1/5，自定义最高建议 30）、wait_timeout_ms（默认 30000，0 无期限）、on_match=`run_script|stop`、action_script_id、on_timeout=`stop|retry|run_script`、timeout_script_id、max_retries（默认 0）、retry_delay_ms（默认 1000）、trigger=`rising_edge|every_match`（默认 rising_edge）、cooldown_ms（默认 1000）。失败脚本只能用于等待超时；引擎错误不触发失败动作脚本。

正常路径：验证配置和脚本 → 获取输入执行租约 → 首轮立即捕获 → 周期识别 → 命中输出编号、坐标和证据 → 记录 `target_detected` → 同步执行成功动作子脚本，将 RecognitionResult 放入 `args.match` → 记录结果 → 单次结束或持续监控。纯监控 on_match=stop 不发输入，首次命中即 completed，repeat 必须为 false。on_timeout=run_script 时，失败脚本成功返回则 completed(reason=timeout_handled)，失败脚本报错则 failed；两种情况都不继续监控。

| 情况 | 行为 | 状态/用户反馈 |
|---|---|---|
| 未命中且未到等待时限 | 不执行成功动作，按周期继续 | running，显示最近检测时间 |
| 持续命中同一目标 | rising_edge 模式只触发第一次；观测到未命中才重新布防 | 不重复点击 |
| every_match | 动作完成、冷却结束后，新帧仍命中可再触发 | 不并发运行同一动作 |
| 等待时限耗尽 | stop：终止并标记 timeout；retry：最多 max_retries 次新等待周期；run_script：失败脚本运行一次后结束 | 记录第几次尝试和终止原因 |
| 瞬时 CAPTURE_FAILED | 同一轮 200ms 后最多重试一次，不突破总期限 | 成功才进入识别 |
| OCR 超时/模型缺失/图像无效 | failed，记录具体错误 | 不当作未命中，不自动重复动作 |
| 成功/失败动作脚本报错 | failed，传播子调用栈 | 默认不重跑，避免部分动作重复 |
| 一轮超过周期 | 跳过过期 tick，只保持一个在途识别 | 显示实际 Hz 及节流状态，不堆积任务 |
| 用户暂停/断点 | 停止调度，释放按键，冻结运行时限 | paused；恢复先验证区域/窗口，重新采样 |
| 用户取消/停止 | 立即关闭输入闸门，取消等待和子调用，丢弃迟到匹配 | stopping → cancelled；不执行失败脚本 |
| 窗口移动/缩放 | 作废旧帧及匹配，按新客户区版本重新采样；ROI 不再合法则暂停 | 不按旧坐标点击 |
| 区域失效/窗口关闭 | 区域变小不再合法则暂停并提示停止重选；窗口关闭则失败终止，需重新选择后开启新执行 | failed，WINDOW_NOT_FOUND / INVALID_REGION |
| 无目标/无脚本/频率非正/重试无穷 | 开始前拒绝 | 保留配置，定位字段错误 |

等待时限统计有效监控等待时间；动作执行、冷却和暂停不占此时限。一次命中重置等待时限。重试次数仅在等待超时增加，命中后清零；默认无自动超时重试。根执行总时限（如设置）覆盖等待、动作、冷却及重试，暂停时间除外。频率是目标调度频率，不是 OCR 吞吐保证。

## F05 脚本执行与互调

**纯脚本**：编写并保存 Lua → 校验语法与参数 → 选择 once/count/forever/until_target → 运行。count 的 N 为正整数；每次执行顶层脚本创建新的局部环境。forever 默认没有一小时隐含上限；可显式设置总时限。until_target 在每轮前及运行检查点检测停止目标，命中后停止剩余步骤；单次不可中断原生推理不能保证瞬时中断，但后续输入必须被阻止。

**互调**：`call_script(script_id,args)` 同步执行已保存脚本，JSON 复制传参及一个返回值；父调用等待，子调用共享执行 ID、输入租约、区域、停止信号和根时限。每层独立参数与变量。深度最大建议 5（含根）；错误默认传播，父脚本可用 pcall 处理普通错误；停止不可被捕获后继续发输入。不能通过调用子脚本获得文件/网络访问。

异常：语法错在启动前定位行；运行时错显示脚本/行/调用栈；错误返回值（循环 table、函数、NaN）报 SERIALIZATION_ERROR。默认不自动重试有副作用脚本。重复点击运行不产生第二个根任务；已有三个活动根时，新根返回 BUSY。

取消未运行的编辑不影响已保存脚本。退出应用先停止执行并等待清理；进程崩溃不自动重放。目标库/配置变更在下一次根执行生效，避免运行行为无提示改变。

## F06 区域限定与窗口绑定

用户选择当前打开的可见应用窗口，展示标题、进程名和 PID；内部绑定窗口句柄+PID+进程创建时间，避免句柄复用误绑定。绑定仅当前会话。默认要求目标窗口处于前台、未最小化；自动化调用前重新检查，失焦/最小化暂停并释放输入，用户恢复窗口后手动继续；关闭终止，不自动绑同名窗口。

识别边界永远限制在所选区域；`allow_exit` 仅控制程序模拟的鼠标是否可越出该区域，不扩展识别范围，也不锁住真人鼠标。绑定窗口时客户区仍是输入硬边界；允许移出 ROI 也不能移出该客户区。未绑定时允许移出 ROI 可使用当前选定显示器；不含虚拟屏幕空隙。

输入越界拒绝整个动作，不钳制到边缘。拖拽检查整条路径；严格模式起点在区域外时要求用户先移入，程序不私自跨界。键盘不能空间裁剪：绑定模式检查前台身份；未绑定模式 UI 明示输入发往当前前台。不能保证键盘快捷键的效果只改变区域内像素。

## F07 调试、日志、热键

断点在执行相应 Lua 行之前暂停；step_into 进入子脚本，step_over 越过当前调用，step_out 返回上一层；暂停时只读查看变量、调用栈。编辑脚本后断点与源码 hash 绑定，旧行号需重新校验。首版不提供可产生副作用的任意表达式求值。运行恢复收起实时调试日志，历史保留供主动查看。

Ctrl+Alt+S 框选、Ctrl+Alt+X 停止、Ctrl+Alt+P 暂停/恢复为建议默认热键；系统注册冲突时提示重新分配，保存失败保留旧配置。停止热键注册成功是允许发输入的启动条件之一；UI 停止按钮始终可用。热键不受 Lua 执行线程或 OCR 阻塞。

日志包含执行 ID、时间、状态、目标编号、命中/未命中摘要、动作及错误码。输入文本和脚本参数默认不记录全文；截图默认不进日志；显式 log 由用户负责内容，UI 支持清空和查看。建议按 10MiB×5 文件轮转，写盘失败提示并保留内存摘要，不阻塞停止。

## F08 配置、恢复与退出

配置字段逐项验证，非法更新整笔拒绝。用户取消设置不更改文件；保存成功后显示生效范围（立即/下次执行/重启）。热键立即应用，识别及运行参数对新执行生效，模型目录变更需重新初始化 OCR。恢复默认值先显示差异，只改设置，不删目标或脚本。

损坏配置保留原文件并提示恢复备份；未确认前不覆盖。引擎退出时 UI 显示不可用，所有活动根执行失败，释放程序按下的输入。重启引擎只恢复服务，不恢复此前动作。所有可写数据位于用户数据目录，安装目录只读。
