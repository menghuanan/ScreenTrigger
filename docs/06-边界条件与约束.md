# 边界、错误与资源约束

本文件为错误码和建议限额的唯一来源。用户确认约束不可被配置关闭；其他数值是工程建议，必须经 [TEST-015](agent/验收与测试.md) 验证后冻结。不能用本表冒充性能实测结果。

宿主 ABI 主版本不兼容时，原生界面展示诊断并禁用业务运行。捕获侧无法排除界面或坐标变换已失效时，终止该次框选、释放临时帧并恢复主窗，按本页错误契约报告原因。

## 硬需求与建议限额

| 项目 | 规则 | 性质 |
|---|---|---|
| 框选最小尺寸 | 宽高各≥10物理像素 | 用户已确认；不是 OCR 准确率保证 |
| 屏幕范围 | 一次选区完整处于一个显示器或绑定客户区 | 建议首版行为；API 不自动裁剪 |
| 输入区域 | 严格模式禁止程序输入越界；allow_exit 不扩大识别区 | 用户要求的两种模式 |
| 坐标 | 物理像素、半开矩形；虚拟桌面可负坐标 | 一致性契约 |
| 区域复用 | 只存在内存，不保存工作区 | 已确认 |
| 识别频率 | 默认1Hz，快捷5Hz，自定义0.1–30Hz | 默认/可更高已确认，范围建议 |
| 并发 | 3 活动根执行（用户 2026-10-09 确认）；同步子调用；每执行最多 1 识别在途 | 用户确认，取代单根建议；输入闸门串行派发，各根独立租约 |
| Lua 调用深度 | 5层（含根）；源码≤1MiB；JSON≤1MiB/32层 | 建议 |
| Lua 内存 | 每个根执行树的 Lua 堆合计建议128MiB；不含 OCR 模型 | 待 allocator/worker 实测，不伪称进程 RSS 限额 |
| 图片文件/像素 | 导入≤50MiB；解码≤40,000,000像素，宽高各≤16384 | 建议；先检查解码预算，避免 4K PNG 被旧10MB限额误拒 |
| 图片缓存 | 建议256MiB，按字节LRU；超限淘汰无引用帧 | 内存不足返回资源错误，不共享失效指针 |
| 目标/分组 | 10000目标、1000分组、最多3层层级（用户 2026-10-09 确认） | 用户确认的工作限额，不是 JSON 格式理论上限 |
| 目标条件 | 1–10叶、深度≤4，名称1–100字符 | 建议 |
| 脚本总时间 | 默认0不限；可显式设 total_timeout_ms | 不再隐含一小时截止 |
| 单次推理 | 5s；超时丢弃结果并清理/重启 worker | 建议；不是所有语言500ms保证 |
| 普通 IPC / 启动 | 5s / 30s；长运行异步返回 ID | 建议 |
| 停止清理 | 闸门立即关闭，worker最多2s优雅退出后终止 | 建议；已派发 OS 事件不可撤回 |
| UI 预览 | 默认10Hz，最新帧覆盖，坐标独立更新 | 建议；与识别频率独立 |
| 日志 | 默认10MiB×5轮转；历史默认保留最近100个执行 | 建议；有活动执行不删除当前日志 |

超过限额在启动或调用前返回明确错误；不要一处截断、一处拒绝。只有明示的候选列表、变量快照、日志分页允许截断且必须标识。until_target 的停止检查按 frequency_hz 采样；真实识别慢时实际频率降低，界面显示 effective_hz。

## 坐标、区域与输入不变量

1. 不能对虚拟屏幕绝对 x/y 直接乘 DPI。WinUI 覆盖层以 HWND 客户区的物理屏幕原点及当前 XamlRoot.RasterizationScale 转换 XAML 局部 DIP；先转换矩形边界，再用差值求宽高。
2. 截图为物理像素；OCR bbox 先从裁剪局部平移回 frame.space，再转屏幕；中心不误当左上角。
3. 读取系统指针失败返回 WINDOW_UNAVAILABLE，不能将 (0,0) 当作成功读数。屏幕点必须落在实际显示器集合，不能只验证虚拟屏幕总包围盒（显示器之间可能有空隙）。
4. 窗口变动后 geometry_revision 增加，旧帧不可用于输入。绑定以身份元组验证，不能只按标题或旧 HWND。
5. 对动作整体验证，非法端点/路径拒绝；不做 clamp，不让动作先执行一半再发现确定可预知的越界。运行过程中新增窗口变化仍需逐步检查并及时中止。
6. Input 每个活动根执行一个租约（并发上限 3），持有账本由 Rust 管；暂停、停止、故障、退出均释放本程序持有的键/鼠标按钮。
7. 不能限制用户真人鼠标。严格区域不等于限制键盘快捷键的业务作用域；必须在 UI 明示。

## 时间、取消与重试

所有持续时间用单调时钟，不受系统时间调整影响；墙钟只作日志。暂停扣除计时；单次原生推理本身超时不因 UI 暂停无限延后。恢复舍弃暂停前帧并重新采样。

stop 从任意活动状态进入 stopping，先关闭 Rust 闸门，再通知 Python。Lua count hook、API 前后检查及可取消 wait 共同确保忙循环可停。原生推理不可中断时可完成后丢弃或终止 worker，不阻塞输入闸门。终态不可复活，迟到的成功结果只记录为丢弃。

只自动重试瞬时捕获失败一次（200ms）；等待超时重试按 MonitorConfig 的有限策略；OCR 模型错误、参数错误、存储冲突、键鼠动作不自动重试。配置或数据写超时状态未知先查询 revision/request，不用重复请求 ID 以外的新 ID 重发。

## 错误码注册表

错误结构 `{code:string,message:string,details:object,retryable:boolean}`。retryable 表示条件变化后允许调用方尝试，不授权框架自动重跑动作。取消不是错误码，使用 cancelled 状态。未命中不使用 TARGET_NOT_FOUND（该码指样本库没有此 ID）。

| code | 触发 | 处理/默认 retryable |
|---|---|---|
| INVALID_PARAMS | 类型、范围、枚举错误 | 定位字段，false |
| INVALID_STATE | 状态不允许操作 | 查询最新状态，false |
| BUSY | 根执行/框选/队列占用 | 停止或等待，true |
| CONFLICT | revision或ID内容冲突 | 重新加载/合并，false |
| IN_USE | 删除活动执行引用 | 停止后再操作，false |
| NOT_FOUND | job/request历史等实体不存在 | 刷新，false |
| PROTOCOL_ERROR | 畸形帧/版本/消息类型错误 | 停止会话/重连，false |
| UNKNOWN_COMMAND | 未注册命令 | 更新客户端，false |
| DUPLICATE_EXPIRED | 重复请求已知但响应已淘汰 | 查询实体，false |
| ENGINE_UNAVAILABLE | 进程退出/不可用 | 清理输入，允许用户重启，true |
| INTERNAL_ERROR | 未分类内部故障；请求超时（普通 5s 到期）亦用本码，message 附期限与 request_id | 诊断并终止当前操作，false |
| DISPLAY_NOT_FOUND | 显示器消失 | 重新选择，false |
| INVALID_REGION | 太小/越界/空间不匹配 | 重新框选，false |
| INVALID_IMAGE | 解码失败、非法模板/格式 | 更换图，false |
| IMAGE_EXPIRED | 图像引用过期或不属于会话 | 重新捕获/导入，false |
| CAPTURE_FAILED | 驱动/瞬时捕获失败 | 最多一次自动重试，true |
| TARGET_NOT_FOUND | 目标库无该ID | 修正引用，false |
| GROUP_NOT_FOUND | 分组不存在 | 刷新列表，false |
| MODEL_UNAVAILABLE | 模型未安装/损坏 | 安装或修复离线模型，false |
| LANGUAGE_UNSUPPORTED | 模型声明不覆盖请求语言 | 选择可用模型，false |
| RECOGNITION_TIMEOUT | 单次识别超过5s | 停止本次，用户可降频/缩区，true |
| RECOGNITION_FAILED | OCR/轮廓/模板内部故障 | 记录模型和输入摘要，false |
| SCRIPT_NOT_FOUND | 已保存脚本ID缺失 | 更正引用，false |
| SCRIPT_SYNTAX_ERROR | Lua 编译错误 | 修正行列，false |
| SCRIPT_RUNTIME_ERROR | Lua 未处理错误 | 调试调用栈，false |
| SCRIPT_TIMEOUT | 根执行期限耗尽 | 终止并清理，false |
| WAIT_TIMEOUT | 监控等待到期且策略停止 | 终态失败；Lua wait函数本身返回false，false |
| CALL_DEPTH_EXCEEDED | 子调用第6层 | 改脚本结构，false |
| SERIALIZATION_ERROR | 非JSON参数/返回 | 修正数据，false |
| CAPABILITY_DENIED | 使用未提供的宿主能力 | 改用允许API，false |
| INPUT_FAILED | SendInput返回失败/不完整 | 不自动重试，false |
| REGION_LIMIT_VIOLATION | 输入点/路径越界 | 改参数/范围，false |
| STALE_FRAME | 几何版本变更 | 丢弃并重新识别，true |
| WINDOW_NOT_FOUND | 身份失效/已关闭 | 当前根执行失败，false |
| WINDOW_UNAVAILABLE | 失焦/最小化/遮挡导致不可操作 | 暂停等待用户处理，true |
| HOTKEY_CONFLICT | 全局注册失败 | 选其他热键，false |
| STORAGE_ERROR | 磁盘不足/被占用/落盘失败 | 保留旧数据和草稿，true |
| DATA_CORRUPT | JSON/hash/外键校验失败 | 保留原文件，选择备份恢复，false |
| SCHEMA_UNSUPPORTED | 数据版本高于当前软件 | 升级软件，不降级覆盖，false |
| RESOURCE_LIMIT | 内存/像素/数量超预算 | 降低规模，false |

## 日志与诊断

普通模式仅显示状态/错误摘要，不弹实时日志窗口。日志记录每次动作的 action_id、执行 ID、目标编号、时间与 dispatched/error，不记录输入文本及参数全文；输入失败无法证明应用是否已部分接收，界面说明“请检查目标窗口后决定是否重新运行”。日志故障不能阻塞停止或破坏主数据；日志中的源码/变量仅在用户进入调试时按限额展示。

Windows 锁屏、UAC 安全桌面、受保护窗口不作为正常截图和注入目标；拒绝或暂停并说明。首版不提权绕过，也不宣称能检测所有遮挡形式；动作点用前台/窗口命中检测尽量避免误点，完整复杂遮挡支持需探针验证。

配置损坏时按 F08 自动恢复已校验的备份，并显示恢复修订。无效备份和未来 schema 保持只读。引擎重启后，历史中的未终止执行显示为失败（engine_exit）；查看或清除终态日志不会重新派发输入。

恢复预览验证备份格式、原图和脚本哈希，确认时持目录写锁复验两侧指纹。未来 schema 返回 SCHEMA_UNSUPPORTED。已有有效目录先生成并复核保护备份；损坏的 current 保留原字节和原 generation。磁盘故障、活动执行、内容寻址冲突或并发新写入均中止切换。恢复所需的临时文件和保护备份均写在目标卷上。

当 current 损坏，恢复还须核对保留的各代样本编号上界。若原目录已无法核实分配过的编号，保留现场，并提示把备份恢复到新的空目录。
