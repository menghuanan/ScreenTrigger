# 模块接口与修改边界

接口为设计签名，不是可执行 Python。共享类型按 [02](02-数据结构.md)，错误按 [06](06-边界条件与约束.md)。所有长调用接收 CancelToken，抛出 DomainError；结果缺失与调用失败不得共用 None 表示。

## 通用约定

- `async` 接口不能阻塞 IPC reader；原生推理在 worker 中执行。
- 使用不可变请求/结果值；帧字节由 ImageStore 访问，不广播到所有 UI 事件。
- 所有写操作校验 expected_revision；成功响应表示已落盘。
- 下列 `desktop/ScreenTrigger/` 和 `native/host/` 是迁移目标路径，现有 `src/` 和 `src-tauri/` 供迁移核对。WinUI 窗口适配仅操作本应用窗口，外部窗口身份和输入授权仍属 Rust。

## M01 Capture

允许修改 `backend/capture/`、`desktop/ScreenTrigger/Selection/`、`desktop/ScreenTrigger/Import/`、`native/host/src/selection/` 和 `native/host/src/import/` 及对应测试。负责桌面帧、显示器与选区，不保存目标。

| 接口 | 输入 → 输出 | 失败/约束 |
|---|---|---|
| `list_displays() -> list[DisplayInfo]` | 无 → id、物理 rect、dpi_scale、primary | ID 在会话内稳定，拓扑变化重新枚举 |
| `capture(region: Region, binding: WindowBinding?, cancel) -> Frame` | 区域/可选绑定 → 帧引用、captured_at、origin、geometry_revision | INVALID_REGION、CAPTURE_FAILED；不自动裁剪 |
| `import_image(import_token: str) -> ImageRef` | 文件选择器授予的一次性 token → 已解码引用 | 校验格式、大小、方向；脚本不接收文件路径 |
| `begin_selection(display_id: str?) -> SelectionSession` | 选屏/默认 → selection_id | 一个会话；先等待脚本暂停 |
| `finish_selection(selection_id, region) -> ImageRef` | 合法物理区域 → 无覆盖层最终帧 | 最小 10×10；恢复主窗口放 finally |
| `cancel_selection(selection_id) -> None` | ID → 无 | 幂等，恢复窗口，释放临时引用 |

完成证据：TEST-001 所有 DPI/取消/隐藏/实时画面用例，截图不含选择覆盖层。

帧登记：截图命令（`capture`/`capture_full_screen`/`capture_window`）除返回 `Frame` 外，**登记帧元数据**（`space/origin/geometry_revision/binding_id/captured_at/frame_id`）至会话图像注册表（与像素同生命周期）；`import_image` 登记 `image_pixel`/origin=(0,0)/geometry_revision=0/binding_id=null。选择覆盖层的选区派生帧暂不登记几何（回退 `image_pixel`）。

## M02 Vision

允许修改 `backend/vision/` 及模型 manifest、对应测试。仅接收帧和条件快照，不读可变目标库、不操作键鼠。

| 接口 | 输入 → 输出 | 失败/约束 |
|---|---|---|
| `recognize_text(frame, model_id, cancel) -> list[TextBlock]` | 帧/模型 → 原文、分数、polygon | MODEL_UNAVAILABLE、RECOGNITION_TIMEOUT |
| `match_template(frame, image_ref, threshold, cancel) -> list[Candidate]` | 模板与帧 → 去重候选框 | 纯色/零方差模板拒绝；尺寸不匹配明确报错 |
| `match_contour(frame, image_ref, threshold, cancel) -> list[Candidate]` | 轮廓参考 → 候选 | 不伪称像素模板已覆盖轮廓需求 |
| `detect_color(frame, color_params, cancel) -> list[Candidate]` | RGB/HSV → 连通域和覆盖量 | 容差及 hue 环回按 02 |
| `evaluate_target(frame, target_snapshot, cancel) -> RecognitionResult` | 同帧条件树 → 编号、候选和证据 | 先 anchor，再候选局部判断 |

缓存键至少含帧 hash、target revision、模型版本、算法参数和坐标版本；命中旧帧不直接用于新动作。完成证据 TEST-004/TEST-015。

算法链落地：`match_template`（TM_CCOEFF_NORMED + 可选尺度）、`match_contour`（灰度 → 固定 Canny → 外轮廓 → `matchShapes I1`）、`detect_color`（适配器内 BGR/RGB/HSV → 8 连通分量，分散像素不拼大框）。`image_id → Frame` 由**同一会话图像注册表**解析（Vision 经 `StoreFrameResolver` 只读同一 store，**不引入 `Vision→Capture` 依赖**）；未登记 → 诚实回退 `image_pixel`。缺 cv2/numpy 时三个算法 Provider 诚实降级（能力 unavailable + reason，调用 `ENGINE_UNAVAILABLE`）。

OCR 落地（TASK-015）：第 4 个内置 Provider（`condition_type=ocr`）`initialize` **只加载显式已安装模型**（构造引擎显式传本地 `model_name` + `model_dir`，禁用隐式联网下载，`enable_mkldnn=False`）；缺引擎/缺模型/内容损坏分别抛 `ENGINE_UNAVAILABLE`/`MODEL_UNAVAILABLE`/`DATA_CORRUPT`，能力诚实置 `unavailable + reason`（规范格式见 03）。`recognize_text` 输出 `TextBlock`（`polygon` 为**源图 0 基像素**、`space == frame.space`，**不做** origin 平移；平移由消费层 `textmatch.translate_polygon_to_space` 完成且只做一次）。模型元数据（逐文件 sha256 + 许可证 + 语言）见仓内 `manifest/models.catalog.json` 与 02 布局 `models/<model_id>/manifest.json`；**权重二进制不入仓库**（留在权重库根，缺省 `~/.paddlex/official_models`，`ST_OCR_MODELS_DIR` 可覆盖）。`textmatch` 提供 NFC 归一 + `exact`/`contains`/`fuzzy` 纯匹配（相似度非概率）。

## M03 Target / Repository

允许修改 `backend/targets/`、`backend/storage/`、`desktop/ScreenTrigger/Targets/`。图片、分组与目标在一个 generation 提交。

| 接口 | 输入 → 输出 | 失败/约束 |
|---|---|---|
| `create_target(draft: TargetDraft) -> Target` | 名称/图/条件 → 稳定 ID、sample_no、revision | 保存成功后才展示已保存 |
| `get_target(target_id) -> Target` | ID → 对象 | TARGET_NOT_FOUND |
| `list_targets(group_id?, query?, offset=0, limit=100) -> Page[Target]` | 过滤 → items,total | limit 1–500；排序 sample_no |
| `update_target(target_id, patch, expected_revision) -> Target` | 白名单 patch → 新 revision | 禁改 ID/sample_no，CONFLICT |
| `delete_target(target_id, expected_revision) -> None` | ID → 无 | 活动快照引用时 IN_USE |
| `create_group(name, parent_group_id?) / update_group(id, name?, parent_group_id?, revision) -> Group` | 名称/父组 → 层级分组（≤3 层）；`update_group` 支持 `parent_group_id` 搬移（键缺省=不搬移、显式 `null`=移至顶层；`name`/`parent_group_id` 至少给一个） | 空名/同层同名拒绝；父组存在且层级不超 3 |
| `delete_group(id,revision) -> None` | ID → 目标成员移至未分组，子分组提升到被删组的父位置 | 单次事务，禁止级联删除目标 |
| `move_target_to_group(id,group_id?,revision) -> Target` | 新分组 → 新目标 revision | 分组存在性校验 |
| `Repository.read_snapshot() -> CatalogSnapshot` | 无 → 一致 generation | 不读一半新一半旧 |
| `Repository.commit(change, expected_generation) -> CommitResult` | 变更 → generation | 写锁、校验、备份、原子 current 指针 |

SQLiteAdapter 必须通过同一 Repository 合约测试，首版只提供接口与迁移设计。完成证据 TEST-003/TEST-012。

## M04 Script / Monitor

允许修改 `backend/script/`、`backend/monitor/`、`desktop/ScreenTrigger/Scripts/`。拥有运行状态；不直接调用 Win32。

| 接口 | 输入 → 输出 | 失败/约束 |
|---|---|---|
| `start_script(config: RunConfig) -> ExecutionState` | 参数/脚本快照 → starting + execution_id | 受理不代表完成；BUSY/语法错启动前拒绝 |
| `start_monitor(config: MonitorConfig) -> ExecutionState` | 区域/条件/动作 → starting | 临时会话，不写工作区 |
| `pause(id) / resume(id) / stop(id) -> ExecutionState` | 当前 ID → 状态快照 | stop 幂等且优先；resume 必须校验窗口 |
| `state(id) -> ExecutionState` | ID → 权威快照 | 终态按历史保留策略可查 |
| `call_child(ctx, script_id, args: JsonValue) -> JsonValue` | 参数复制 → 单一返回值 | 深度限制，共享 cancel/lease/deadline |
| `save_script(id?, source, name, expected_revision?) -> Script` | UTF-8 源码 → 版本 | 不执行；语法检查单独返回行列 |
| `validate_script(source) -> list[Diagnostic]` | 源码 → 诊断 | 仅编译，不能模拟执行验证 |

每迭代创建新环境；宿主运行检查点覆盖 API 调用前后、Lua count hook、wait 切片。Monitor 是 Script controller 的调度策略，不另起输入执行器。TEST-007/TEST-008/TEST-010/TEST-011。

## M05 Input（Rust）

允许修改 `native/host/src/input/` 及 Python 窄代理。实际 OS 输入只有本模块可调用。

| 接口 | 输入 → 输出 | 失败/约束 |
|---|---|---|
| `acquire_lease(execution_id, context) -> LeaseId` | 执行/区域/窗口 → 租约 | 一根执行一个租约 |
| `dispatch(lease, action: InputAction, action_id) -> ActionAck` | move/click/drag/key/text → dispatched/拒绝 | 同 action_id 去重，不承诺外部应用已接受 |
| `close_gate(execution_id, reason) -> None` | 取消或故障 → 立即拒绝新输入 | 不等待 Python 回应 |
| `release_owned_inputs(execution_id) -> None` | 账本 → key-up/mouse-up | 尽力清理；不释放不属于本程序的按键 |

禁止坐标钳制、自动重试动作、默默抢焦点、直接发未校验路径。Unicode 文本用 SendInput Unicode 路径探针验证；不默认改剪贴板。TEST-005/TEST-008。

## M06 Window（Rust）

允许修改 `native/host/src/window/` 和 `desktop/ScreenTrigger/RunContext/`。

`list_windows() -> list[WindowInfo]`；`inspect(window_id) -> WindowInfo`；`bind(window_id) -> WindowBinding`；`unbind() -> None`；`snapshot(binding) -> WindowSnapshot`。

WindowInfo 包含句柄字符串、PID、进程创建时间、标题、客户区物理 rect、可见/最小化/前台状态。WindowBinding 是不透明 ID；窗口身份失效不得自动按标题重绑。geometry_revision 在移动/缩放/DPI/客户区变化时递增。通知 Script 暂停或终止，不自行继续执行。TEST-006。

## M07 Debug

允许修改 `backend/debug/`、`desktop/ScreenTrigger/Debug/`。通过 Script 的私有控制端口工作，用户 Lua 环境不暴露 debug 库。

`add_breakpoint(script_id, source_hash, line) -> Breakpoint`；`remove_breakpoint(id)`；`list_breakpoints(script_id)`；`step(execution_id, kind: into|over|out) -> ExecutionState`；`variables(execution_id, frame_id) -> VariablePage`。

变量是序列化只读快照，有 depth=5、items=100、string=4096 字符预算；循环引用显示引用标记，不能导致整个响应失败。仅 debug_paused 状态允许 step/variables；不支持任意表达式执行。TEST-009。

## M08 IPC 与共享配置

允许修改 `native/host/src/ipc/`、`backend/ipc/`、`desktop/ScreenTrigger/Host/`；只能路由已注册命令。`dispatch(request) -> response`、`emit(event)`、`cancel_request(id)`，完整契约见 03。

ConfigService：`get_config() -> Config`、`update_config(patch, expected_revision) -> Config`、`reset_config(expected_revision) -> Config`。只合并已知字段，深层校验，写入成功才返回；热键变更失败回滚注册与配置。

Logger：接收结构化 RunLog，普通运行写盘/内存而不持续推送 UI 日志。ImageStore：`put / get / release` 使用不透明引用，检查会话所有权和像素预算。TEST-012/TEST-013/TEST-016。
