## TASK-001 依赖、模型与运行时探针

**需求理解**：证明 Python 3.13.x、离线 OCR、OpenCV/Pillow、Lua 5.4/Lupa 在 Win10/11 x64 可安装、可运行、可断网；不能用降低 Python 版本制造成功假象。**非目标**：不实现业务 OCR、Lua API 或安装器。

**前置**：无。**设计**：定义隔离 venv、包/模型/许可证 manifest、语言与符号覆盖、能力 unavailable、失败阻塞 A02/A05/A07 的规则；分清包版本、模型版本和 Lua ABI。

**编码范围**：tools/probes/python_ocr_probe.py、tools/probes/lua54_probe.py、探针依赖模板、reports/TASK-001/。**步骤**：固定 OS/Python/架构/CPU/GPU；离线安装候选；OCR 测空图、无字、多行、旋转、混合语言、数字、标点、缺模型；Lua 测 _VERSION、JSON、line/count hook、忙循环停止、内存接口；输出矩阵、hash、许可证和替代方案。

**测试/完成**：TEST-002 与 TEST-010 的探针子场景；断网、缺模型、错误 hash、忙循环、子调用；产物可由同一命令重建，能力清单可供 hello 使用，不兼容项显式阻塞。**启动指令**：

> 阅读 U08/U10/U14、D03-D06、R01/R03/R11 和 07，实现 Python3.13、离线 OCR、Lua5.4 隔离兼容探针，运行断网/缺模型/忙循环测试，产出版本矩阵、模型 manifest、许可证和阻塞结论。

**需求理解**：验证 Per-Monitor V2、负虚拟坐标、实时干净捕获、覆盖层排除、SendInput Unicode、前台窗口和 geometry_revision。**非目标**：不建业务模块。

**前置**：无。可与首个依赖探针并行。**设计**：用独立 C# / XAML 主窗口和顶层框选窗验证原生迁移可行性，确定物理坐标、DisplayInfo/WindowInfo/Binding、窗口隐藏恢复、输入闸门最小接口和真实 Windows 证据格式。

**编码范围**：tools/probes/windows/（含独立 WinUI 3 x64 探针）、reports/TASK-002/。**步骤**：测试 100/125/150/200/300% DPI 及负坐标；在每个目标 Win10/11 build 上以动态桌面计时器核对预览和最终图无主窗、无覆盖层且非黑块，记录 HWND、XamlRoot 缩放、坐标和焦点恢复；移动/缩放/最小化/失焦/关闭验证身份和几何版本；测试补充平面 Unicode、组合键、拖拽取消、停止后的输入计数；给出库/OS 限制。

**测试/完成**：TEST-001/TEST-005/TEST-006/TEST-008 的 OS 部分，记录每屏坐标误差、预览 p95、退出/取消恢复及覆盖层捕获排除结果；早期 Windows 缺排除能力时实测替代实时路径，未达标的 build 保留阻塞。**启动指令**：
