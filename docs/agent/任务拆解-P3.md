## TASK-027 Windows 打包与离线安装

**需求/非目标**：WinUI 3 程序、Rust DLL、受控 Python sidecar 和已验证模型打包并可离线安装；不依赖用户 PATH 或隐式网络。**前置**：TASK-003、TASK-004、TASK-015、TASK-019、TASK-026。

**设计**：WinUI 入口、x64 安装方式、.NET 和 Windows App SDK 自包含输出及其附加依赖、模型许可证/hash、已存在的用户数据根与升级/卸载策略。**编码**：原生工程发布配置、离线安装脚本、reports/TASK-027、安装文档；锁定 DLL/sidecar/模型路径，参数数组启动，生成 hash 和清单。

**测试**：TEST-014 干净 Win10/11 x64、无系统 Python/.NET 开发工具、断网冷启动、缺模型、从既有目录升级及卸载；记录实际包体/磁盘/内存/启动时间。**完成**：核对默认启动项、包内文件、依赖和进程树，所有应用 UI 走 WinUI 3，运行不加载 WebView2 前端。缺模型可纯脚本，既有目标/脚本/设置可读，许可证和哈希可追溯。**启动指令**：

> 阅读 D01-D04、00/02/07、用户指南和 TASK-002/TASK-015/TASK-019/TASK-026，设计并实现 Windows 离线安装包、受控 Python/模型资源、WinUI/.NET 依赖、缺模型降级和升级卸载，运行 TEST-014 并提交包体及启动证据。

## TASK-028 数据备份恢复与迁移设计验证

**需求/非目标**：首版完成 generation/资产备份、预览恢复、Repository 扩展接口和 SQLite 迁移设计验证；不实现 SQLite 导入器、切库、运行时双写或实际迁移。**前置**：TASK-010、TASK-011、TASK-012、TASK-027。

**设计**：资产闭包、manifest/hash/外键、恢复预览、版本兼容、新写入保护；书面核对未来迁移的实体映射、临时库校验、失败保留 JSON 和切换后新增数据回滚条件。**编码**：backend/storage/backup.py、CLI/WinUI 3 设置页中的备份、恢复预览和确认弹窗、Repository 接口合约测试；备份完整 current generation，恢复前校验版本/预算，保留旧数据并拒绝无保护覆盖。

**测试**：TEST-012 磁盘故障、current 损坏、未来 schema、资产缺失、恢复失败与已有新写入保护；迁移只审查设计和接口，不以运行 SQLite 为通过条件。**完成**：备份恢复不建空库、不丢编号/条件/资产；接口与迁移设计有审查证据；首版不需要 SQLite 运行依赖。**启动指令**：

> 阅读 02/06/07、R07、U12 和 TASK-010/TASK-011/TASK-012/TASK-027，实现完整 generation 备份/预览恢复及 Repository 扩展接口，审查未来迁移设计，运行 TEST-012 首版故障恢复测试。实际 SQLite 迁移维持后续版本范围，不计入首版未完成项。

## TASK-029 全量验收、性能报告与发布门槛

**需求/非目标**：执行 TEST-001-TEST-016 并生成可审计发布报告；不通过修改产品语义或用文档检查替代运行验收。**前置**：TASK-001-TASK-028。

**设计**：冻结测试机/模型/数据集 hash、失败分级、性能分位数、回归矩阵和发布阻塞规则。**编码**：tests/acceptance 中的业务验收用例、固定 fixtures；复用现有 tools/run_acceptance.py 和 reports/audits 汇总机制；执行 docs 静态检查、契约/单测/集成/真实窗口/OCR 数据集、安装/恢复。

**测试**：TEST-001-TEST-016；报告 preview p95、停止关闸 p95、实际 Hz、模板/轮廓 precision/recall、每语言 CER、2小时资源曲线。**完成**：候选包里对照迁移清单逐项验证原生页面、独立窗口和应用对话框，由同一应用入口走通纯脚本与识图路径，每个 S01-S09 有直接证据；未运行/失败明确；安全不变量不能豁免。**启动指令**：

> 阅读产品 S01-S09、A10、TEST-001-TEST-016 和风险记录，使用现有全局检查运行器，接入实际业务测试并生成发布报告，在固定 Windows/模型/数据集环境执行功能、性能、安装、恢复和停止安全测试，更新风险与发布门槛而不掩盖失败。

## 任务交接回报模板

任务：TASK-nnn / 所属 Axx；实施状态：NOT_STARTED、IN_PROGRESS、IMPLEMENTED；验收状态由检查器计算；需求理解：Uxx、Sxx及非目标；设计：边界、数据流、状态、错误和重试；修改：文件路径及关键接口；测试：命令、环境、结果和报告路径；未覆盖：未运行的 TEST-nnn/平台场景；风险：Rxx、依赖或待确认项；结论：是否满足完成标准、是否允许下游开始。

所有任务使用[检查与闭环](检查与闭环.md)的强制自查项；运行主检查入口导出逐条设计、产物、测试与完成条件目录，不能仅核销任务标题。
