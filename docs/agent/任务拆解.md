# Agent 任务拆解目录

本目录把 A01-A10 阶段摘要拆成 29 个可以直接交给 Agent 的原子任务。每个任务都要求：理解需求、检查前置、设计接口和失败路径、编码、测试、回报证据。原生界面的迁移起点、当前可达页面及切换门槛见[迁移设计](../winui3-migration.md)。任务实施与验收状态以账本及审计为准。

## 使用规则

选择依赖已满足且状态为“待开始”的最小任务，复制对应启动指令。Agent 必须先读产品定义、技术决策、执行约定和本任务卡，再检查工作树；不得假设前置任务真的完成。设计记录至少说明需求/非目标、数据流、接口、状态、错误、重试和测试策略；与已确认要求冲突时停止并报告。

完成时必须报告实际修改文件、命令及退出状态、测试覆盖、未覆盖场景、风险和是否允许下游开始。只写代码或只写“设计完成”不能解除依赖。归档只读；不降低 Python 版本，不改用 Electron，不向 Lua 开放文件/网络/任意 Python 对象，不绕过 Rust 输入闸门，不把未命中当识别错误，不自动重试已派发输入。

## 通用启动协议

读取指定文档 → 复述范围/非目标 → 检查前置产物 → 设计边界/数据/状态/错误/测试 → 编码 → 按检查目录逐项测试并保存证据 → 运行 tools/check-docs.ps1 与任务自查入口 → 修复、复验并关闭异常 → 回报真实证据、未覆盖和风险 → 核验通过后解除下游依赖。
