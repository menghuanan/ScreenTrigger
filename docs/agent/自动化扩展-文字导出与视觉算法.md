# 自动化扩展实施设计 · 文字导出与视觉算法

本版实装中、英、日、韩四语 OCR、ORB 最佳单纹理目标匹配和指定 TXT 导出。YOLO 交付接口契约与正负契约向量。下文标注“待实现”的接口供实施 Agent 与现有类型对接；算法及性能参数按实测登记。

## 起点与改动位置

| 现有能力 | 已核实的入口 | 本版实施范围 |
| --- | --- | --- |

## 从区域字符到指定文件

**已确认。** 运行前选择 TXT 文件，默认每次识别后按行追加，保留前后两次识别及同一帧中的重复文字。用户可切换为覆盖模式，每次成功写入以本次识别的全文替换旧内容。本轮不提供自动去重选项。

1. 运行前由用户选定本次导出的 TXT 文件并设置追加或覆盖模式。受信任的选择器把目标交给 Rust 宿主，签发限于该文件、模式与会话的一次性准备令牌。创建执行或监控成功时消费令牌并绑定执行 ID，重复启动按原请求查询。取消选择、启动失败或令牌过期时不创建、不修改文件；执行终止后撤销授权。
2. Lua 继续用现有 `ocr` 读字符。导出已启用时，识别完成事件提交一次文本快照。宿主写入接口示例 `export_text(output_id, text)` 待实现。脚本只取得不透明的输出标识；一次识别只分配一个导出动作 ID。
3. 按横排阅读顺序排版。将文字框转为轴对齐矩形，按上缘、左缘、源序升序处理。以每行首块固定其垂直区间，和新块的垂直交集高度除以两块较小高度，比例 ≥0.5 归入该行。多个行组满足时选重叠比例最大者，再以首块顺序决胜；均不满足则新建一行。
4. 单次脚本和连续监控统一消费对应识别事件中的 `TextBlock[]`。监控可传递同帧结果或保留该帧再推理。禁止为写文件另取后一帧；一次逻辑识别若命中缓存，仍产生本次导出事件。
5. 启用区域 OCR 监控后，每次识别返回文字都排队导出，以采样序号维护顺序。现有目标命中、冷却和超时动作独立调度；它们不能吞掉连续相同文本的导出事件。写入跟不上时节流后续采样，报告实际频率和失败状态。[监控调度器](../../backend/monitor/scheduler.py)

每行按左缘、上缘、源序排序；行按首块上缘、左缘、源序排序。保留有效非空块的原文、标点与已有空格；相邻两块之间若均无边界空白则插入一个 ASCII 空格。各行和块内已有换行统一为 CRLF；快照在末行补齐行终止符。数字、组合音标、重复块和低置信度原文都参与排序，诊断可附分数。

**文件写入与故障恢复**

| 场景 | 行为与可观察结果 |
| --- | --- |
| 第一次写入 | 首个有字快照写 UTF-8 无 BOM，换行字节为 0D 0A。保存现有文本时校验其 UTF-8 编码，若已有 UTF-8 BOM，在同一原子提交中移除；其他编码追加前返回可解释错误。 |
| 覆盖 | 在目标目录写同卷临时文件，刷盘后原子替换。替换前重新核对授权目标和预期版本。原文件已被其他程序修改时返回冲突，保留外部编辑的内容。 |
| 追加 | 按目标文件串行提交一条完整快照。原文件末行无终止符则先补 CRLF；已有 LF 或 CRLF 时直接追加。小文件采用校验旧文件、合并和原子替换；按实测速率及文件大小选择是否使用有恢复日志的追加。 |
| 幂等 | 宿主以执行 ID、逻辑导出动作 ID 和目标授权识别一次写入。一个动作超时重试时沿用同一 ID；用提交记录和文件前后指纹识别重启前已成功的写入。相同 ID、不同内容返回冲突。 |
| 连续重复 | A→A→B→A 的四次识别有四个动作 ID。追加模式依次写四行 A、A、B、A；覆盖模式执行四次提交，最终文件为 A。帧内两处相同文字按各自的位置保留。 |
| 空读或低置信度 | 空帧或无文字时两种模式都保留原文件字节，尚无文件时不创建。导出保留识别器返回的低置信度原文，同一事件记录分数。推理或写入失败返回错误，原文件保留。 |
| 取消与退出 | 原子提交前取消可丢弃临时文件，提交后返回已有回执。停止后不启动新写入，已提交内容保留；如进程恰在替换后退出，按同一 ID 和文件指纹核实结果。 |

受控写服务保管实际路径。限定授权模式、失效时间和归属，按最终文件身份或受信的父目录与文件名复核重解析点、路径替换、别名与共享冲突；追加和覆盖同一目标共用排他写入规则。外部修改导致无法确认原状时要求重新选定。
脚本保留现有可信脚本边界。输出授权只供写入文本，图片导入令牌不能转成写令牌。宿主响应建议包含结果、写入字节数、逻辑动作 ID；普通诊断避免写入识别原文，只记录耗时和错误类别。[Lua API](../04-Lua脚本API.md) · [既有令牌实现](../../native/host/src/import/token.rs)

## 本版运行能力 · 四语 OCR 与 ORB

中文、英语、日语、韩语复用现有 OCR 模型映射与识别入口。覆盖完整的区域→识别→四语原文→TXT 路径。按候选包分别复验四语、符号、混排、无字与小字，不得将 UTF-8 文件编码成功计作识别正确。[模型映射](../../manifest/models.catalog.json) · [验收矩阵](验收与测试.md)

- **适用目标。** 每次在有效区域中查找一个有纹理的平面图标或图块，只返回分数最高且通过几何检查的一个候选；无合格候选返回空。沿用候选框、分数、来源与几何版本，供 `find_target`、组合条件和监控复用。
- **候选计算。** 建议用已锁定的 OpenCV 检查 ORB 可用性，计算样本和场景描述子，采用与 ORB 参数一致的 Hamming 距离筛选匹配，再用 RANSAC 拟合约定的几何变换。只有有效内点及投影形状达到阈值才输出候选。[OpenCV 匹配方法](https://docs.opencv.org/4.x/dc/dc3/tutorial_py_matcher.html) · [OpenCV 单应性验证](https://docs.opencv.org/4.x/d1/de0/tutorial_py_feature_homography.html)
- **选择与拒绝。** 对通过内点数、内点比例、重投影误差、投影面积和凸性检查的候选，按未舍入分数降序、内点数降序、重投影误差升序、框的 (y,x,w,h) 字典序取首个。去掉完全相同的框；固定测试随机种子。低纹理或不成立的几何关系返回空，依赖或推理故障另报错误。
- **缓存。** 按样本内容哈希、裁剪范围、算法版本和参数缓存描述子；来源图或参数变化即失效。仅复用样本描述子，场景帧和窗口几何须保持新鲜。[条件评估器](../../backend/vision/condition_evaluator.py) · [视觉缓存](../../backend/vision/cache.py)

## YOLO 扩展接口 · 本版契约向量

本版交付请求、结果、能力状态、错误及以下测试向量。使用内存中的合成帧、类别和解码结果；候选包不含 YOLO 权重或新增推理运行时，无需真实检测、训练数据或指定类别图片。测试替身仅参与契约检查。
请求沿用 Frame、ROI、取消标记与 Provider 生命周期。模型声明约定模型 ID、版本、类别 ID、输入尺寸、颜色与数值范围、缩放补边、输出张量布局及是否需要外部重叠框抑制。未来装载时再核对权重哈希与再分发许可。[YOLO 导出格式](https://docs.ultralytics.com/modes/export/)
结果引用源帧与几何版本，含类别、分数、源帧范围内的候选框；允许有效空候选。对未知类别、非有限分数、负尺寸、过期或取消的请求分别规定拒绝结果。检测器实例未配置时返回能力不可用，不能登记为 available。

| 合成向量 | 输入与预期 |
| --- | --- |
| 正向 · 坐标和类别 | 源帧局部 ROI 为 (100,50,200,100)，缩放 2 倍后上下各补 100 到 400×400。构造声明内类别、分数 0.9、网络边界 [20,120,100,180] 的记录。期望源帧框 (110,60,40,30)，保留类别、分数与源帧版本。 |
| 正向 · 无目标 | 合成后处理返回合法空候选，保持当前帧的正常未命中语义。 |
| 负向 · 非法输入 | 分别给未知类别、非有限分数、倒置框或模型输出形状不符，断言拒绝且无候选。非有限分数用内存浮点数构造；在线格式用非法 JSON 验证协议拒绝。 |
| 负向 · 生命周期 | 运行入口缺 Provider 时返回能力不可用；已取消或过期帧的合成结果不得触发脚本。以上均可在无权重环境验证。 |

| 条件接口 | 资源及叶参数 | 与现有执行路径的连接 |
| --- | --- | --- |
| `feature_match`（待实现） | 使用目标样本图，参数含所需最少内点数、内点比例、最大重投影误差。用调参集标定默认值并写明单位。 | 评估器当前仅为部分叶准备样本图，需要接通新类型；作锚点时搜索整帧，作附加条件时按同一候选的局部区域验证。 |
| `object_detect`（接口预留） | `model_id`、类别 ID 和阈值由合成模型声明驱动正负向量。 | 契约说明逐实例返回与同帧坐标语义，实际工厂保持未装配。 |

ORB 接入前同步权威数据结构、能力清单、三端类型及校验、条件序列化与评估器、协议版本和错误表。检查子进程接收的源帧、样本图和取消信号。YOLO 接口契约单独版本化，契约夹具不改变生产工厂。[条件校验](../../backend/types/conditions.py) · [数据契约](../02-数据结构.md) · [IPC 契约](../03-IPC协议.md)
组合条件在同一候选区域取证。对重复图标或多个检测实例定义排序、截断和重叠框处理；对“颜色出现在甲、文字出现在乙”的异物组合沿用拒绝规则。Lua 现有返回结构继续解析旧条件和样本。
ORB 输入使用源帧像素，检测器的网络输入尺寸只用于推理。窗口客户区、屏幕物理坐标、图片像素各保留来源；在截图边界、负原点和更改 DPI 后测试框能还原到原对象。窗口移动后丢弃旧帧。
旧模板多尺度可选，代码的隐式默认范围 0.95–1.05 与显式参数上界 1.0 存在差异。先加回归用例并对齐规格与校验，不能据此承诺跨比例的定位质量。[模板实现](../../backend/vision/providers/template.py) · [参数验证](../../backend/types/conditions.py)
实际 OCR 与 ORB 继续在可取消的子进程中运行，监控优先丢弃过期帧。验证超时、取消、进程退出、重建及缓存释放。旧结果晚到时不触发导出或脚本动作。[推理隔离](../../backend/vision/process_provider.py)

### ORB 留出集计分

沿用现行视觉质量测量方法，ORB 留出集至少 200 张正样本、200 张负样本，每张图作为一次“给定样本，在 ROI 定位最佳一个实例”的查询。按采集会话和原始图片分组拆分，同源连拍、裁剪、旋转和缩放版本同属一组。调参与留出不交叉。记录样本图、场景图、框标注及划分清单哈希；在解封留出集前固定实现、阈值、随机种子与依赖版本。
正图标注可接受的实例框集合，最终预测与其中任一真值的半开矩形交并比 IoU ≥0.50 记 1 TP。空预测记 1 FN；误定位同时记 1 FP 和 1 FN。负图有预测记 1 FP，空预测记 1 TN。额外输出框即违反单框契约。重复运行同分夹具须返回同一位置。
汇总全部留出样本，未舍入的 TP/(TP+FP) ≥0.95 且 TP/(TP+FN) ≥0.90 才达标；没有预测时精确率不可评估，不能通过。若回看测例后改参数，该批改作诊断集，使用独立冻结留出集复验。
