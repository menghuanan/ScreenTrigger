# 暂缓测试清单

2026-11-25 核对。当前无法完成的正式测试统一标记为 **暂缓执行，后续开发完成后统一测试**。按运行所需条件归为 **9 个环节**，覆盖首版 16 个 TEST 组。表中每组只计一次，可以共用测试环境和任务产物。此标记只安排测试时间，任务验收和硬依赖由检查器根据逐项证据判定。

## 本机已核实

- 正式 WinUI 主窗已联通 Rust DLL 和项目 Python，引擎重启后以新会话返回配置修订。独立框选探针在 2560×1440、100% 上验证动态预览、成图、边界和取消恢复。发布账本的 `release_artifact` 为空。
- 项目解释器为 CPython 3.13.14 x64。74 个 wheel 已从本地介质按哈希核对。4 个 OCR 模型共 22 个文件均与模型目录哈希一致。探针在本机真实识别中文和英文，并对权重缺失和损坏分别返回约定的错误码。
- 早期辅助解释器的配置服务、目标 Repository 和 Python IPC 三组记录为 67/67。当前显示探针仅观察到 100%，混合矩阵记录为 `NOT_RUN`。
- Rust 和 Cargo 1.100.0（x64 MSVC）已按原生宿主的新锁文件构建 DLL。本机专用输入窗记录了补充平面 Unicode、组合键、越界与失焦拒绝，以及关闸后释放自有输入。原始日志见本地账本。
