# 暂缓测试清单

2026-11-25 核对。当前无法完成的正式测试统一标记为 **暂缓执行，后续开发完成后统一测试**。按运行所需条件归为 **9 个环节**，覆盖首版 16 个 TEST 组。表中每组只计一次，可以共用测试环境和任务产物。此标记只安排测试时间，任务验收和硬依赖由检查器根据逐项证据判定。

其中 **3 类条件需要改变当前测试环境**，分别是能实际断网的测试系统、带混合 DPI 和负坐标的交互桌面，以及干净的 Win10 与 Win11 x64 系统。断网和干净系统可用同一组隔离快照，多屏也可通过调整本机显示配置获得。其余 6 个环节可在本机补齐对应产物、工具、样本或专用测试窗口后执行，其中涉及上述条件的子场景共用相应环境。

## 本机已核实

- 核查期间已出现 `native/host/Cargo.toml`，本机已列出 .NET SDK 11.0.100。正式 WinUI 主窗与独立框选窗的启动、关闭及对接 Python 仍缺实测记录。发布账本的 `release_artifact` 为空。
- 当前 Win11 x64 可用 Python 3.12.14 做辅助诊断。本轮用仓库既有测试分别验证了模型目录校验和 Provider 错误映射，7/7 通过，包含正确、缺失及损坏的样本。正式权重与离线依赖的验证仍由环节 1 承接。
- 在同一辅助解释器上，配置服务、目标 Repository 和 Python IPC 三组共 67/67 通过，覆盖临时数据目录、故障注入和协议样例。显示探针记录的实际缩放只有 100%，混合矩阵的内部状态为 `NOT_RUN`。
- Rust 和 Cargo 1.100.0（x64 MSVC）已可调用。对原生宿主和旧工程分别按锁文件离线重编时，本地依赖索引缺少 `serde`，均在编译前退出。当前源码的按键释放用例仍待复验。工作区的核查记录与原始日志位置见本地账本相应问题单。
